# Значок приложения

Авторский знак «согнутый лист»: бирюзовый металл, светлый торец и радиус на тёмной плашке. Утверждён пользователем 2026-10-27; SVG и производные изображения распространяются под MIT проекта.

`application.svg` — редактируемый исходник. `16.png`–`256.png` включаются в Qt resources, `application.ico` — в Windows EXE. PNG/ICO хранятся в Git: сборка приложения и CI не требуют графического редактора, Pillow или Qt SVG.

После изменения SVG выполнить из корня `python3 scripts/generate_app_icons.py` и просмотреть результаты. Для этой отдельной команды нужны Inkscape и Pillow; это инструменты разработки, не зависимости приложения. Малые PNG экспортируются из SVG в собственном размере. ICO содержит кадры 16/24/32/48/64/128/256.
