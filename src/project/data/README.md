# Стартовые DXF-снимки v1

Фиксированный набор подготовлен 2026-11-01 по прямому поручению владельца проекта из выбранных записей его мастерской. Сборка не читает настройки, Загрузки или другие личные папки. Исходные DXF/PDF/DWG, архив удалённых записей, пути и личные количества в комплект не включаются. С 2026-11-03 D152 добавляет отдельно согласованные типовые количества для первого запуска.

Данные сечений отделены от MIT-лицензии исходного кода. Это предоставленные для стартового комплекта технические профили, а не новые авторские заводские чертежи. Происхождение и ограничения описаны в [контракте](../../../docs/starter-tool-library.md) и [лицензионном реестре](../../../docs/licensing.md).

В JSON `segments` — редактируемый стартовый набор прямых секций с положительными количествами; он переносится только в новую мастерскую. Это не личный склад и не паспортная комплектация изготовителя; карточка помечает типовой состав. Существующие файлы не дополняются. Изменять набор следует явно через ревью данных и проверку `app.starter-tools`, а не повторным захватом текущего пользовательского каталога. Сечения/SHA исходных DXF при D152 не изменены.
