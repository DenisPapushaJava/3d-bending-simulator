# История изменений

## Не выпущено

- Расширена поддержка деталей с подрезанными торцами, составными полками и совместными зонами гиба.
- Улучшен совместный поиск порядка гибов и сборок инструмента. Добавлены установки у края инструмента и отдельные зазоры между секциями.
- Исправлено направление сечений на чертеже. Добавлены выбор положения сечения, смена направления взгляда и ручное перестроение.
- Улучшены компоновка видов и размещение размеров. Поле количества постоянно доступно на панели.

## 2026.1.0-alpha.3

Экспериментальный выпуск для Windows 10/11 x64. Основные изменения — задние упоры, подбор инструмента по форме детали и более управляемые чертежи.

**Скачать и запустить:** распакуйте весь [3d-bending-simulator-2026.1.0-alpha.3-windows-x86_64.zip](https://github.com/DenisPapushaJava/3d-bending-simulator/releases/download/v2026.1.0-alpha.3/3d-bending-simulator-2026.1.0-alpha.3-windows-x86_64.zip) в отдельную папку и запустите `3d-bending-simulator.exe` в корне. При необходимости установите Microsoft Visual C++ 2015–2022 x64 Runtime. Исходники зависимостей и SHA256SUMS — отдельные материалы, для запуска нужен Windows ZIP.

Изменения относительно alpha.2:

- Два упрощённых пальца заднего упора с общей X и регулируемой высотой R. Для новых назначений проверка включена по умолчанию. Предпочитается прямой край листа, затем реальная стенка уже выполненного гиба 90°. Пальцы отображаются в 3D; контакт, диапазоны и столкновения проверяются вместе с установкой, включая четыре положения отвода по X.
- Для обычного контакта лист остаётся на матрице, нижняя кромка площадки упора располагается на 0,1 мм выше неё. Короткие кромки поддерживаются без искусственного минимального разноса контактов, с сохранением двух конечных контактов и проверки тел пальцев.
- Поиск повторно использует точные отказы базирования, раньше отбрасывает подтверждённые невыполнимые установки и предпочитает большую часть материала со стороны оператора. Подбор инструмента учитывает соседние полки, близкие разнонаправленные гибы и полный DXF-корпус матрицы/пуансона.
- Чертёж: выбор видимых видов, общий масштаб связанных проекций и отдельные масштабы развёртки/изометрии/сечений с перекомпоновкой. Подготовка и компоновка выполняются в фоне; есть отмена, повтор и пояснение отказа прямо в предпросмотре.
- Автоматическая ориентация по основным плоским поверхностям детали; габариты боковых проекций и локальные выноски радиусов. Исправлены размерные базы между соседними и обратными гибами, улучшено размещение плотных размеров. Направления ВВЕРХ/ВНИЗ на развёртке привязаны к показанной стороне и указаны выносками к линиям гиба.
- Убраны лишние служебные надписи PDF. Имя файла предлагается по имени STEP со словом «чертёж», запоминается последняя папка сохранения. Готовый векторный план повторно используется при перерисовке и экспорте.
- На чистом запуске стартовая библиотека содержит типовые ненулевые секции/количества для проверки программы. Это демонстрационный состав, не фактические остатки мастерской; существующая библиотека не заменяется.
- Скорость просмотра — 1×–10×; новая 1× соответствует прежней 3×. Окно подбора инструмента центрируется по главному окну и блокирует ввод в него до закрытия.
- Сохранение проектов `.bend` v16 с параметрами упора; чтение прежних версий сохранено. Новые проекты следует открывать в актуальной версии приложения.
- Для разработки сокращён цикл F5: сборка только приложения; полная сборка/CTest доступны отдельно. В CI компиляция использует четыре задачи, тесты — две, сохраняя обе ОС и весь набор проверок.

**Ограничения:** программа остаётся очень ранней alpha. Упоры и станок упрощённые: координаты кинематические, не для ЧПУ; удержание детали, непрерывное движение, перенос/извлечение и физика материала не подтверждены. Проверка дискретных положений не доказывает безопасность всего движения. Поиск ограничен бюджетом; отсутствие найденного порядка не доказывает невозможность изготовления. Развёртка теоретическая, часть геометрий и размерных наборов не поддержана полностью. PDF содержит справочные размеры и не является утверждённой технологической документацией. Интерактивная проверка на целевом Windows/GPU остаётся необходимой; CI offscreen её не заменяет. Архив не подписан.

## 2026.1.0-alpha.2

Экспериментальный выпуск для Windows 10/11 x64: от STEP-детали и выбора реального инструмента до ручного/автоматического порядка, геометрической проверки и справочного PDF с развёрткой.

**Скачать и запустить:** распакуйте весь `3d-bending-simulator-2026.1.0-alpha.2-windows-x86_64.zip` в отдельную папку и запустите `3d-bending-simulator.exe` в корне. Для перехода с alpha.1 нужен новый ZIP; старый опубликованный комплект автоматически не обновляется. При необходимости установите Microsoft Visual C++ 2015–2022 x64 Runtime.

Изменения относительно alpha.1:

- Три рабочих этапа: Деталь / Инструмент / Гибка. Единая панель задачи, лента 0…N прямо в 3D, воспроизведение ×1–×3, куб видов, якорь вертикали Y, более равномерное освещение и F5 для восстановления сцены без CAD-пересчёта.
- Ручной порядок с drag-and-drop, Undo/Redo и просмотром промежуточных состояний без полного поиска. Автоматический ограниченный поиск поддерживает до 32 гибов, ранжирует перспективные варианты и повторно использует состояния/переходы; есть отмена и явное расширение бюджета.
- Подбор пары инструмента вместе с проверенным маршрутом. Быстрый подбор и ручной выбор остаются доступны; «Подобрать секции» сохраняет выбранные профили. Назначение с шага 0 относится ко всей детали, с положительного шага — к соответствующему гибу. Развороты детали и пуансона независимы.
- Реальные DXF-профили в симуляции и проверках. Добавление только из подготовленного DXF с измерением сечения, графический выбор профиля/ручья, многоручьевые матрицы и поддержка вложенных BLOCKS/INSERT. Малый V ограничивается общими правилами материала/толщины, а не отдельными примерами деталей.
- Единая библиотека: профиль, название, длины/количества секций, спокойные цвета длин, редактирование, удаление и восстановление. Секции/зазоры участвуют в проверках. На чистом запуске доступны семь реальных профилей без выдуманных складских остатков; существующая мастерская не заменяется.
- Демонстрационная сборка DemoPressV3: держатель пуансона, адаптер матрицы с посадочными углублениями, траверса, стол, боковые рамы и пол. Эти препятствия участвуют в покадровой проверке независимо от видимости.
- Воспроизведение останавливается на столкновении. Локальные красные пятна и подтверждённые прямые полосы показывают найденные места контакта на обеих поверхностях. Короткий инструмент блокирует обычное движение; отдельный диагностический просмотр включается явно. Предупреждения собраны в компактной панели во вьюпорте.
- Постоянный файловый кэш геометрии инструмента/сборок и повторное использование готовых ручных кадров. Смена установки сохраняет сцену и камеру; повреждённый или устаревший кэш перестраивается.
- Расширен импорт STEP с проверенными дефектами оформления и вспомогательными кривыми; улучшено определение толщины тонких многогибочных профилей. Поддержаны составные торцы прямых гибов и настраиваемый локальный допуск нехватки опоры у торцов с предупреждением.
- После загрузки доступны материал, распознанная толщина и правило теоретической развёртки. Для новых деталей предложен K = 0,45 с возможностью изменить его или выбрать справочный расчёт. Развёртка открытых связных листовых деталей показывается в 3D и PDF, исходные отверстия остаются видимыми.
- Справочный лист: классические виды, истинные сечения, размеры полок/внутренних углов/R/t/L, привязки отверстий и вырезов, изометрия и размеренная развёртка. Стандартные масштабы и читаемая компоновка по возможности на одном листе; подтверждённая повторяющаяся волна показывается крупно один раз. Предпросмотр немодальный, с переключением страниц, масштабом и переносом.
- Режим «Стороны A/B» сохраняет спокойные синий/терракотовый цвета поверхностей при разворотах, развёртке и гибке; метка края 1 помогает узнавать положение детали. Переключение не запускает расчёт.
- В комплекте четыре наглядных STEP: уголок с отверстиями, П-профиль, лоток с четырьмя гибами и панель L1000 с 16 гибами. Папка: `runtime/2026.1.0-alpha.2/share/3d-bending-simulator/examples`.
- Переносимый `.bend` v14 читает прежние версии; библиотека v5 сохраняет удалённые записи. Ручная команда «Справка → Проверить обновления…» и новый portable-формат с отдельными runtime/data предусматривают проверку ZIP/SHA-256, перезапуск и восстановление; фоновых проверок нет.

Границы экспериментальной версии:

- Геометрический просмотр не рассчитывает физику материала, пружинение, деформацию отверстий, нагрузку, устойчивость детали или реальное крепление. DemoPressV3 — приближённая учебная геометрия, не точная цифровая конфигурация SPEED BEND. Упоры и перенос/извлечение между установками не моделируются.
- Подвод/гибка и препятствия проверяются в дискретных положениях; непрерывная проверка относится к поддержанному вертикальному отводу пуансона. Исчерпанный бюджет поиска не доказывает невозможность изготовления; найденный маршрут не является производственным сертификатом.
- Развёртка теоретическая и требует калибровки по материалу/инструменту/образцам. В упрощённом режиме влияние замкнутых вырезов игнорируется при расчётах, но исходные отверстия отображаются. PDF — справочный лист, без заявления полного соответствия ЕСКД. DXF-экспорт развёртки ещё не реализован.
- Импортируется отдельная STEP-деталь; сборки и родные SolidWorks/КОМПАС-3D не поддержаны. Возможности распознавания/развёртки не покрывают любую форму. Точные трёхмерные сапожки и их автоматическая сборка ещё не реализованы. Выбор ориентира A/B/края пока не сохраняется в `.bend`.
- Интерактивная работа на Windows/GPU и применение обновления между двумя реальными Windows-версиями ещё требуют проверки. CI проверяет сборку, тесты и запуск упакованного приложения без интерактивного GPU. Архив не подписан.

Рядом с Windows ZIP опубликованы соответствующие исходники зависимостей и `SHA256SUMS.txt`; это отдельные материалы, для обычного запуска нужен только Windows ZIP.

## 2026.1.0-alpha.1

Первый экспериментальный выпуск для Windows x64. Приложение помогает осмотреть STEP-деталь, подобрать инструмент по параметрам, проверить поддержанный отдельный сгиб и подготовить справочный лист готовой формы.

- Фоновое открытие STEP/STP одной детали через диалог, командную строку или перетаскивание; отмена, диагностика и сохранение предыдущей модели при ошибке.
- Просмотр OCCT/OpenGL: выбор грани, габариты, куб навигации, стандартные ракурсы, режимы отображения, размерные выноски и быстрое закрытие детали.
- Автоматическое предложение толщины, ручное уточнение и локальное распознавание прямых цилиндрических зон с подсветкой, внутренним радиусом, углом и длиной.
- Переносимые проекты `.bend` v5 со встроенным STEP, параметрами детали и выбранным инструментом; чтение версий v1–v4 сохранено.
- Три этапа работы: «Деталь», «Инструмент», «Проверка». Каталог параметрического инструмента и предварительный подбор пары по детали; просмотр доступного исходного профиля не подтверждает его пригодность для контакта.
- Геометрический просмотр одного поддержанного сгиба: плоская установка, подвод, гибка на двух опорах и отвод пуансона, воспроизведение со скоростью 1×–3×.
- Отверстия и замкнутые вырезы остаются видимыми. В упрощённом режиме проверки опор, пересечений и отвода используют отдельную заполненную копию с явной пометкой приближения.
- Справочный лист на A3 и PDF: выгодная ориентация, истинные местные сечения, размеры полок/толщины/радиуса, внутренние углы между стенками, количество и привязки осей видимых круглых и поддержанных симметричных вытянутых отверстий. При необходимости используются два позиционированных сечения переменной стенки.
- Авторский значок окна/панели задач и Windows EXE. Учебные STEP-примеры, лицензии и соответствующие исходники зависимостей входят в поставку.
- Windows OCCT включает FreeType для размерных чисел и подписей куба; используется системный sans-serif вместо привязки к Linux-шрифту. Растеризация кириллицы проверяется без GPU, в том числе из подготовленного комплекта.
- Проверки C++/Qt/OCCT в CI на Windows и Linux; Windows portable ZIP, исходники зависимостей и SHA-256 готовятся только по релизному тегу.

Ограничения первого выпуска:

- Импортируется отдельная деталь из одного корректного STEP-тела. Сборки и родные форматы SolidWorks/КОМПАС-3D не поддерживаются; из CAD нужно экспортировать STEP.
- Распознавание локальное и неполное. Движение нескольких гибов и автоматический поиск порядка ещё не реализованы; подбор по параметрам не подтверждает крепление, нагрузку, опору и отсутствие столкновений.
- Просмотр геометрический: он не рассчитывает физику материала, пружинение, деформацию отверстий и технологическую развёртку. Непрерывная проверка относится только к вертикальному отводу нашего параметрического пуансона; подвод/гибка проверяются в отдельных положениях.
- PDF — рабочий справочный лист готовой формы, не утверждённый чертёж и не подтверждение полного соответствия ЕСКД. Неподдержанные измерения отмечаются явно.
- Интерактивная работа на Windows/GPU ещё требует проверки. Архив не подписан; на Windows может потребоваться Microsoft Visual C++ 2015–2022 x64 Runtime. Встроенное обновление ещё не реализовано.
