# Примеры деталей

Четыре наглядные детали входят в стартовый комплект. Откройте нужный STEP из этой папки обычной командой «Открыть» или перетащите его в окно приложения: выберите материал и подтвердите предложенную толщину, затем переходите к инструменту, гибке или чертежу/PDF.

| Пример | Что попробовать |
| --- | --- |
| `profiled-bend-6mm.step` — уголок с отверстиями, один гиб, t6 | Автоматическая толщина, настоящий профиль инструмента, движение, отверстия, развёртка и размеры/PDF |
| `tool-clearance-2mm.step` — узкий П-профиль, два гиба, t2 | Сравнить прямой пуансон и пуансон с выемкой, повернуть его и увидеть столкновения |
| `tray-four-bends-2mm.step` — лоток, четыре гиба, t2 | Менять порядок шагов, разворачивать деталь, подбирать длину секций для закрытых углов |
| `wall-panel-1000mm.step` — панель, 16 гибов, t1,5, L1000 | Распознавание толщины, ручные шаги, развёртка; общий профиль и крупная типовая волна на чертеже |

В новой библиотеке доступны реальные пуансоны и матрицы. Для t6 предварительно подходит V50, для t2 — V16; окончательный результат зависит от формы инструмента, секций, положения детали и проверяемого шага. На профиле для сравнения попробуйте ST1701S и ST1405S с 2067-1/V16. Для сравнения проверен второй ручной шаг с корпусами длиной 835 мм, в обычной ориентации и без модели станка: ST1405S не пересекает деталь в 21 положении, ST1701S пересекает. Проверка конкретного набора описана в документации разработки; отдельная удачная установка не подтверждает изготовление на реальном станке.

Количество секций в стартовой библиотеке не выдумывается. Для лотка и панели укажите своё наличие и нажмите «Подобрать секции». Короткий инструмент блокирует обычное воспроизведение; специальный осмотр доступен через диагностический просмотр. Изменение видимости станка не отключает столкновения.

Оригинальные STEP здесь не перезаписываются при работе: сохраняйте свои настройки отдельным `.bend`. Этот же набор включён в dev-сборку и в релизную папку `share/3d-bending-simulator/examples` (в Windows portable — внутри `runtime/<VERSION>/share`). Старые пластины/острые уголки, дюймовый дубль и диагностические вырезы перенесены в `tests/data/step` и не поставляются пользователю.

Первые три детали созданы проектом из OCCT-примитивов под MIT. Панель 1000 мм — производная предоставленной пользователем CAD-модели, включённая по его поручению; MIT собственного кода не меняет права на исходную модель. Происхождение, SHA и прежние замеры сохранены в `tests/data/step/README.md` исходного дерева. Длинная панель 2700 мм остаётся регрессионным случаем и не входит в пользовательский комплект.

Для панели с обычной сталью и K=0,45 проверен двухлистовый A3: основные виды/общий профиль/крупная волна/изометрия, затем развёртка 1000 × 1176,78 мм. Показаны четыре подтверждённых повтора с шагом 278 мм, внутренние углы около 153,1°, R4, t1,5 и длина зон 1000 мм. Шаг разметки развёртки зависит от материала/K и отличается от шага готовой волны. Чертёж не требует успешного автоматического поиска маршрута.

Генератор `tools/GenerateExamples.cpp` по умолчанию восстанавливает только три собственные наглядные детали:

```bash
./build/dev/bin/step_examples examples
# Служебные регрессионные случаи, отдельно от пользовательского набора:
./build/dev/bin/step_examples tests/data/step --fixtures
```

Степень геометрической проверки не является расчётом усилия, пружинения, крепления или фактической точности готовой детали.
