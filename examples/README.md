# Учебные STEP-примеры

Дата: 2026-10-18. Геометрия создана в этом проекте из примитивов OCCT; файлы и генератор распространяются под MIT проекта. Пользовательские производственные модели и чужие образцы здесь не используются.

| Файл | Геометрия и единицы |
| --- | --- |
| `plate-mm.step` | Параллелепипед 100 × 60 × 2 мм, объём 12 000 мм³; файл в мм |
| `plate-inch.stp` | Та же геометрия, записанная в дюймах; после импорта размеры совпадают с предыдущим примером |
| `angle-mm.step` | Булево объединение двух параллелепипедов: габариты 100 × 60 × 40 мм, объём 19 600 мм³; файл в мм |

Уголок — учебная CAD-геометрия с острым внутренним углом, а не результат моделирования гибки. Пример не подтверждает толщину, припуск, радиус или возможность изготовления.

Открыть через **Ctrl+O** либо передать путь приложению:

```bash
./build/dev/bin/3d-bending-simulator examples/angle-mm.step
```

Воспроизведение после обычной сборки с `BUILD_TESTING=ON`:

```bash
./build/dev/bin/step_examples examples
```

Исходник: `tools/GenerateExamples.cpp`. Генератор задаёт геометрию, единицы, отсутствие сборок и фиксированную дату заголовка; приведённые файлы записаны OCCT 7.6.3. Другая версия экспортёра может изменить структуру и порядок STEP-сущностей при той же геометрии. Для сравнения проверяются размеры/объём и единицы, а не байтовое совпадение файлов.

В готовых комплектах примеры находятся в `share/3d-bending-simulator/examples`, в Linux-пакете — `/usr/share/3d-bending-simulator/examples`. Начальный каталог диалога открытия указывает на доступные примеры; после загрузки используется каталог текущей детали.
