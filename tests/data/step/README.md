D129, 2026-11-01: служебные случаи перенесены из пользовательской папки examples. В комплект приложения они не входят. Четыре наглядные детали остаются в examples; CMake готовит общий build/test-step-data для прежних тестов, без дублирования исходников. Далее сохранены исходные описания и результаты проверок.

# STEP-примеры

Обновлено: 2026-10-31. Исходные учебные примеры созданы в этом проекте из примитивов OCCT и распространяются вместе с генератором под MIT проекта. Стеновая панель `wall-panel-2700mm.step` добавлена из предоставленной пользователем модели по его прямому поручению включить её в примеры; происхождение и границы проверки указаны ниже.

| Файл | Геометрия и единицы |
| --- | --- |
| `plate-mm.step` | Параллелепипед 100 × 60 × 2 мм, объём 12 000 мм³; файл в мм |
| `plate-inch.stp` | Та же геометрия, записанная в дюймах; после импорта размеры совпадают с предыдущим примером |
| `angle-6mm.step` | Учебный уголок из пластин 6 мм: габариты 100 × 60 × 40 мм, объём 56 400 мм³; согласованные локальные расстояния 6 мм |
| `bend-90-6mm.step` | Один цилиндрический сгиб: внутренний R8 мм, толщина 6 мм, поворот 90°, длина 80 мм |
| `profiled-bend-6mm.step` | Один сгиб R8/t6/90°/W80, две полки по 30 мм, два отверстия, зенковка и скошенный угол; независимый пример D024 |
| `bend-zone-hole-6mm.step` | Сгиб R8/t6/90°/W80 со сквозным отверстием внутри зоны: D01, движение недоступно |
| `bend-zone-pocket-6mm.step` | Та же основа с глухим карманом на внешнем цилиндре: D01 |
| `channel-zone-hole-2mm.step` | Две зоны R4/t2/90°/W80: одна полная B01 и одна с отверстием D01 |
| `trimmed-bend-2mm.step` | Один сгиб R4 мм, t2 мм, 90° с наклонно подрезанным торцом: осевой габарит 80 мм, общий прямой участок 74 мм |
| `channel-2mm.step` | Профиль с двумя сгибами: внутренний R4 мм, толщина 2 мм, поворот каждого 90°, длина 80 мм |
| `tray-four-bends-2mm.step` | Лоток: основание 200 × 100 мм, t2, R2, четыре гиба 90° длиной 180/80 мм, четыре отверстия Ø3 и угловые разгрузки |
| `tool-clearance-2mm.step` | Узкий П-профиль: наружные габариты 36 × 40 × 80 мм, t2, R4, два гиба 90° длиной 80 мм; пример влияния формы настоящего пуансона |
| `wall-panel-2700mm.step` | Предоставленная стеновая панель: габариты 1112 × 36 × 2700 мм, t1,5, R4, 16 прямых гибов с поворотом около 26,901° и длиной 2700 мм; STEP AP214 в мм |
| `wall-panel-1000mm.step` | Та же стеновая панель с длиной гиба 1000 мм: габариты 1112 × 36 × 1000 мм, t1,5, R4, все 16 гибов сохранены; STEP AP214 в мм |
| `angle-mm.step` | Булево объединение двух параллелепипедов: габариты 100 × 60 × 40 мм, объём 19 600 мм³; файл в мм |

Примеры `bend-90-6mm.step` и `channel-2mm.step` предназначены для [распознавания прямых сгибов](../../../docs/bend-recognition.md). После выбора материала/толщины открыть **Проверка**: доступны ручные шаги и поиск порядка. Шаг **0** — плоская заготовка; остальные кнопки соответствуют операциям в текущем порядке. Для `tray-four-bends-2mm.step` доступны шаги 0–4. Инструмент выбирается из собственной библиотеки; найденный порядок без инструмента не подтверждает отсутствие столкновений.

`tool-clearance-2mm.step`: в локальном опыте с настоящими DXF, матрицей **2030-1 / V16**, длиной сборок 835 мм и обычной ориентацией пуансона **ST1701S** пересекается с деталью во втором ручном шаге. **ST1405S** проходит эти 21 положение и полный двухоперационный цикл с отдельной проверкой вертикального отвода. ST1405M длиной 415 мм также прошёл полный цикл. Проверен порядок распознанных B01 → B02; разворот ST1405S меняет результат. В опыте станок отключён, проверяется влияние корпуса инструмента. Это ограниченный геометрический результат, не подтверждение нагрузки, крепления или возможности изготовить деталь на реальном прессе. Частные контуры и проекты с ними не включены в публичные примеры; нужно использовать свои записи DXF. Идентичный артикул с другой ревизией контура/ручья/сборки не наследует результат.

Для трёх примеров с контурами в зоне выбрать D01: предполагаемая зона оранжевая, стенки выреза красные. Подтверждение/задание и движение недоступны; для смешанной детали B01 остаётся редактируемым. Поведение и ограничение замкнутыми контурами описаны в [контракте диагностики](../../../docs/bend-zone-openings.md). Деформация отверстий и производственная выполнимость не вычисляются.

Уголок — учебная CAD-геометрия с острым внутренним углом, а не результат моделирования гибки. Локальные расстояния в уголках не подтверждают постоянство толщины всего тела, припуск, радиус или возможность изготовления. При открытии примера 6 мм поле автоматически заполняется предложенным значением и подсвечиваются поверхности измерений.

Открыть через **Ctrl+O** либо передать путь приложению:

```bash
./build/dev/bin/3d-bending-simulator tests/data/step/angle-mm.step
```

Воспроизведение учебных примеров из примитивов после обычной сборки с `BUILD_TESTING=ON` (генератор не пересоздаёт предоставленную стеновую панель):

```bash
./build/dev/bin/step_examples tests/data/step --fixtures
# Три собственных пользовательских примера:
./build/dev/bin/step_examples examples
```

Исходник: `tools/GenerateExamples.cpp` в корне репозитория. Генератор задаёт геометрию, единицы, отсутствие сборок и фиксированную дату заголовка; приведённые файлы записаны OCCT 7.6.3. Другая версия экспортёра может изменить структуру и порядок STEP-сущностей при той же геометрии. Для сравнения проверяются размеры/объём и единицы, а не байтовое совпадение файлов.

В готовых комплектах примеры находятся в `share/3d-bending-simulator/examples`, в Linux-пакете — `/usr/share/3d-bending-simulator/examples`. Начальный каталог диалога открытия указывает на доступные примеры; после загрузки используется каталог текущей детали.

Для `profiled-bend-6mm.step` доступны теоретическая развёртка с видимыми отверстиями/зенковкой (D064), оба просмотра движения и начальная установка. Открыть **Инструмент**, выбрать реальные профили из библиотеки и проверить установку; предварительный ориентир для t6 — V48, ближайший доступный подходящий ручей может быть V50. Учебные пуансон/матрица больше не входят во встроенную библиотеку. Опорные участки этого примера не пересекают отверстия.


## Стеновая панель с 16 гибами

`wall-panel-2700mm.step` получен из предоставленного пользователем `36-04н панель стеновая 2700.SLDPRT` по прямому поручению добавить STEP в examples (2026-10-31). Исходный SLDPRT в комплект не включён. SHA-256 исходника: `0b1433b6ecec02d68727fe8014e9804b64c37b7f3e0ea8165089f77bdb808895`.

Конвертация выполнена локально отдельным открытым [sldprt2step](https://github.com/BlinkingSun/sldprt2step/tree/fa954124f4f126e0c465c8f96454978ac80b812e), ревизия `fa954124f4f126e0c465c8f96454978ac80b812e`, Apache-2.0. Конвертер извлёк B-rep, сообщил об одном теле/134 гранях без предупреждений. В STEP нормализованы имя/дата заголовка и Unicode-запись названия продукта; геометрические сущности сохранены. Конвертер/его исходники не входят в приложение, поддержка SLDPRT этим не добавлена.

Проверено OCCT 7.6.3: исходный STEP уже содержит один валидный solid с положительным объёмом; приложение импортирует 134 грани без диагностик и распознаёт 16 зон t1,5/R4/L2700. Нативный Linux/X11 просмотр при 100% показывает готовую форму и развёртку. Для обычной стали с явно выбранным K=0,45 теоретическая развёртка около **2700 × 1176,78 мм**; материал и коэффициент — условия расчёта, не прочитанная из модели марка/производственная калибровка.

При открытии толщина **1,5 мм предлагается автоматически** по 17 парам плоских стенок и 16 парам радиусов гибов (D113). В форме указано локальное происхождение: постоянство всей произвольной формы не объявляется доказанным. D114: полный поиск и ручная лента поддерживают до 32 гибов. Для панели локально получен 16-шаговый геометрический маршрут без инструмента; это не подтверждает совместимость с конкретной оснасткой и изготовление. Общие ограничения, кэши и проверки — в [контракте больших маршрутов](../../../docs/large-bend-routes.md).


### Укороченный вариант для проверки на станке

`wall-panel-1000mm.step` добавлен 2026-10-31 по поручению пользователя: исходная длина гиба 2700 мм превышает указанное расстояние между колоннами 2600 мм. Новый пример сохраняет поперечное сечение, все 16 гибов, t1,5/R4 и углы исходной панели, но длина каждого гиба — **1000 мм**.

Геометрия получена из `wall-panel-2700mm.step` точным пересечением исходного тела со слоем **Z от −1000 до 0 мм** на всю ширину/высоту, без масштабирования толщины/радиусов/профиля. Начальная плоскость Z=0 сохранена. Исходный файл 2700 мм не изменён (SHA-256 `730ef7849e91452e94f24b6dc601cd652a4fed441f97b2d085c295b4b33fd30e`). Это производная предоставленной пользователем модели, не новый синтетический профиль.

Проверено локально на OCCT 7.6: один валидный solid, положительный объём около 1 766 010 мм³, равный 1000/2700 объёма исходной панели; импорт **102 грани без диагностик**, 16 распознанных зон t1,5/R4/L1000. Программа автоматически предлагает **1,5 мм** по 33 локальным свидетельствам, без ручного задания толщины. Для обычной стали/K=0,45 теоретическая развёртка около **1000 × 1176,78 мм**. Готовая форма и развёртка осмотрены в native Linux/X11 при 100%. Уменьшение длины само по себе не подтверждает отсутствие столкновений во всём маршруте с выбранной оснасткой.

D129: пользовательский STEP 1000 мм входит в комплект по явному манифесту `cmake/example-parts.json`; исходные байты не изменены. D130 добавляет подтверждённую типовую волну в чертёж; прежние измерения/развёртка/симуляция сохранены. Воспроизводимые локальные утилита/логи/снимки — `out/panel-1000mm` (не включаются в комплект).
