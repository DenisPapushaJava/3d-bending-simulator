# Скриншоты для README

Сняты 2026-11-04 в текущей локальной сборке приложения на Linux/X11 с настоящим OCCT/OpenGL-контекстом, при масштабе интерфейса 100%. В окне чертежа отдельно используется масштаб просмотра бумаги.

- Деталь: публичный пример `examples/tray-four-bends-2mm.step`, четыре гиба, толщина 2 мм. Модель создана проектом из OCCT-примитивов под MIT.
- Инструмент: встроенная стартовая библиотека `src/project/data/starter-tools-v1.json`, реальные захваченные DXF-профили и типовые стартовые секции. Личные каталоги и складские остатки не использовались.
- Для примера обычный подбор нашёл проверенный в модели маршрут из четырёх гибов: пуансон 1063, матрица 2067-1/V16, сборки по 180 мм из секций 100 + 50 + 20 + 10 мм.
- Развёртка: низкоуглеродистая сталь, ручной K = 0,45.
- На снимке гибки станок и пол скрыты командами меню вида, чтобы показать рабочую зону крупно. Это меняет только отображение: они учитывались при проверке маршрута, режим проверки не отключался.
- Дополнительный снимок столкновения: та же коробочка, реальные ST1701S и 2067-1/V16, сборки по 180 мм, четвёртый шаг ручного порядка. Обычное воспроизведение остановилось на первом конфликтном кадре 18 из диапазона 0–24. Для наглядности затем ползунком выбрано конфликтное положение 24; запуск в нём заблокирован. Изменение формы инструмента или синтетические маркеры не использовались.
- Изображения общие для русского и английского README; подписи в документах переведены, интерфейс на снимках русский.

Снимки получены из настоящих окон Qt. При захвате главного окна добавлен его OCCT framebuffer: штатный `QWidget::grab()` не включает нативную 3D-поверхность. Содержимое интерфейса и результаты расчёта не дорисовывались.

Происхождение стартовых профилей и условия сторонних компонентов описаны в `docs/starter-tool-library.md` и `docs/licensing.md`.
