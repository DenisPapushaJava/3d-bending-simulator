Дата: 2026-10-17. Статус: редактируемые макеты и переходы в Figma созданы по запросу пользователя; структура и предметные параметры остаются предложением для обсуждения. Пользователем подтверждён только визуальный выбор: светлые рабочие панели и тёмная 3D-сцена.

## Где находится результат

- Открытый через Figwright `@fw` файл: **3d bendinbg simulator** — имя сохранено как в Figma.
- Страница **01 · Рабочие состояния**, ID `0:1`: семь экранов 1600 × 1000 и пояснение сценария над ними.
- Страница **02 · Компоненты**, ID `3:2`: 24 основных компонента, из них пять семейств вариантов; 45 переменных и пять текстовых стилей.
- [Манифест Figma](../design/figma-manifest.json): точные ID кадров, компонентов, переменных и проверенных переходов.
- [Локальные PNG-превью](../design/previews/). Экспорты соответствуют кадрам Figma, а не работающему приложению.

Figwright не вернул ключ файла; проверенной прямой URL-ссылки на файл нет. Для продолжения использовать текущий открытый файл и ID из манифеста, не придумывать file key и не переключать интеграцию без причины.

## Состояния и смысл результата

- **Не проверено**: для выбранных входных данных проверка ещё не выполнена.
- **Проверено**: результат относится к конкретному шагу, выбранной геометрии, инструменту и версии входных данных.
- **Столкновение**: показаны шаг, угол, пара объектов и зона контакта. Воспроизведение остановлено; следующие шаги не помечаются проверенными.
- **Порядок изменён**: перемещение B02 меняет индексы операций, но сохраняет ID гиба. Результаты затронутых шагов теряют актуальность.
- **Геометрическая проверка завершена**: показан объём проверки; это не разрешение на производство и не результат физического расчёта.

В успешном состоянии макет перечисляет движение в каждом гибе, контакты детали с инструментом и самопересечения. Отдельно указаны неподтверждённые подвод/извлечение детали, рама и упоры, усилие и пружинение. Этот состав — предложение для будущего проверяющего модуля, не отчёт о работающем алгоритме.

В первой версии порядок задаётся вручную. «Автоподбор · позже» отключён. Не смешивать будущий автоматический поиск с текущей ручной проверкой и не считать исчерпание поискового бюджета доказательством невозможности изготовления.

## Прототип

Созданы два стартовых потока и 21 источник переходов. Основной путь:

1. Кадр 01: «Выбрать STEP-файл…».
2. Кадр 02: «Подтвердить деталь».
3. Кадр 03: «Задать порядок гибов».
4. Кадр 04: «Проверить маршрут».
5. Кадр 05: «Изменить порядок гибов» — возврат к кадру 04.
6. Кадр 04: «↑ Раньше» — кадр 06 с B02 на шаге 2.
7. Кадр 06: «Проверить маршрут» — кадр 07.

Импорт в этом прототипе переключает на подготовленный экран, а не открывает системный диалог. Drag-and-drop, редактирование значений, каталог, развёртка, сводка и настоящая анимация пока не реализованы. Перестановка показана через «↑ Раньше». Реакции основного пути прочитаны обратно через Figma API; ручное прохождение режима Present не выполнялось.

## Визуальная основа и компоненты

Inter Regular / Medium / Semi Bold; стили Caption 11/16, Body 13/20, Label 13/20, Section 16/24 и Title 24/32. В реализации пригодность шрифта для поставки и читаемость на разных DPI проверяются отдельно.

Семантическая палитра: панель #FFFFFF, фон #F7F9FB, основной текст #1C2938, вторичный #526171, акцент #087F83, сцена #202A36, ошибка #BA3F3B, предупреждение #976316. Цвет не является единственным носителем статуса: есть текст и значки.

Созданы семейства кнопок, статусов, этапов, строк гибов и карточек операций; отдельные компоненты поля и общей оболочки. Текстовые свойства вынесены в component properties. Цвета связаны с семантическими алиасами примитивных переменных; интервалы и радиусы имеют ограниченные scopes и используются в привязках. Это начальный набор для данных экранов, не законченная библиотека всех состояний hover/focus и всех диалогов.

До записи файл был пустым: локальных компонентов, переменных и стилей не найдено; кода, Code Connect и дизайн-ассетов в репозитории не было. Поиск удалённых библиотек через fw не предоставлен, поэтому вывод об отсутствии внешних библиотек не делался.

## Проверка макетов

- Все семь кадров просмотрены на скриншотах, размеры прочитаны обратно: 1600 × 1000.
- Исправлены ширина/высота auto-layout-контейнеров, положение панели параметров, подписи статусов, остановка воспроизведения при ошибке и две обрезки текста в карточках инструмента.
- В семи кадрах: 521 нативный текстовый узел, 239 экземпляров компонентов; семейство Inter без подстановок, image fills отсутствуют.
- Структурная проверка нативных панелей после исправлений не выявила выходов содержимого за контейнеры. Векторная 3D-иллюстрация проверялась визуально; её геометрия за пределами viewport намеренно обрезается.
- Исходные материалы и результаты не проходили тестирование реального приложения: реализации Qt/OCCT пока нет.

## Что спроектировать следующим

Загрузка с прогрессом и отменой; ошибка импорта; неподдерживаемая/неоднозначная геометрия; неполная пара инструмента; добавление и удаление операций; устаревшие результаты; отменённая проверка; библиотека инструмента; сохранение/закрытие проекта; отчёт с областью проверки. Это следующий объём, отдельные полноразмерные макеты пока не созданы.

Для инженерного прототипа необходимо уточнить определение угла, разгибание исходной CAD-детали, выбор неподвижной грани, ориентацию и переустановки между шагами, положение инструмента, допуски контакта и область моделируемого станка. Макет не утверждает готовность этих алгоритмов.


## Сверка реализации с макетом — 2026-10-18

Через @fw получены живые контексты `3:365` (выбор инструмента), `3:471` (этапы), `3:477` (правая панель) и screenshot. Motion inventory `3:365`: complete, 227 узлов, 0 анимированных. В макете четыре этапа сверху по 180×40, gap8, padding16, radius4, accent #087F83 / soft #E5F3F3. Пользователь предложил крупную нижнюю навигацию по аналогии с показанным Profile-T: в Qt этапы перенесены вниз, высота увеличена до64 logical px, ширина делится поровну, Alt+1…Alt+4. Список слева, тёмная сцена и параметры этапа справа сохраняются. Это целевая адаптация к native Qt и реальным возможностям текущего расчёта, не полное копирование демонстрационных экранов. Макет Figma при этой сверке не изменялся.

Play/ползунок находятся над навигацией и появляются при подготовке просмотра. Технические измерения и полный отчёт раскрываются отдельно. «Порядок» сообщает об одной поддержанной операции; демонстрационный многогибовый маршрут/автоподбор из Figma не выданы за работающий расчёт.
