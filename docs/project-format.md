# Проект .bend

## Что восстанавливается

В одном файле находятся исходные байты STEP, выбранная толщина, материал и K-фактор, порядок гибов, назначения инструмента и положение детали по операциям. Назначение содержит снимок оснастки с профилями и секциями. Проект можно открыть без исходного STEP и без той же библиотеки на другом компьютере.

Для чертежа сохраняются реквизиты и количество, набор видов и их масштабы, сторона развёртки, база и ориентация главного вида, разрешение разрывов и ручные параметры сечений. Положение и взгляд сечения входят в проект после успешного явного перестроения. Отдельное сохранение проекта записывает применённые настройки. При следующем открытии «Чертёж / PDF» строит лист по ним.

Выбранный масштаб сохраняется как значение либо «Авто». Сечения привязаны к исходным зонам гибов, отдельно отмечается повторяемый фрагмент. Выносной элемент привязан к исходной зоне и роли вида. При перестроении вновь появившийся вид получает автоматические настройки. Листы PDF, кадры, тесселяция и расчётные отчёты строятся из сохранённых исходных данных.

## Контейнер v20

Первые восемь байтов — `BENDSIM\0`, далее одна карта CBOR. Qt Core читает и пишет её существующими средствами.

| Поле | Назначение |
| --- | --- |
| `format`, `version`, `units` | Идентификатор 3D Bending Simulator, версия схемы и миллиметры для параметров проекта |
| `source` | Имя, SHA-256 и исходный STEP в двоичной строке CBOR |
| `parameters` | Ручная толщина либо автоопределение, материал и правило развёртки |
| `bends` | Упорядоченные записи гибов, геометрические якоря, цели, параметры и ссылки на назначения инструмента |
| `toolAssignments` | Снимки оснастки. Полностью одинаковые назначения используют одну запись |
| `drawing` | Применённые настройки чертежа либо null |

В старых проектах STEP кодировался Base64. В v20 хранится сам поток байтов. Чтение JSON v1–v19 сохранено, запись выполняется в v20. Загрузчик проверяет версию, размеры, SHA-256 и ссылки на оснастку до передачи STEP в CAD. Сохранение использует прежний worker и атомарную замену файла. Редактирование чертежа отмечает проект изменённым собственной ревизией и сохраняет актуальность геометрических расчётов.

На «Коробке пульта» запись уменьшилась с 242 176 до 132 104 байтов с добавленными настройками чертежа. В пяти парных открытиях основное время занял импорт и анализ STEP, около трёх секунд на файл. Изменение формата заметного ускорения полного открытия на этой модели не показало.

Расширение `.bend` также используется для исходников языка Bend. В приложении проекты распознаются по содержимому, а выбор обработчика для двойного щелчка относится к настройкам ОС.
