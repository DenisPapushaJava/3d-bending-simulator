# Графический выбор реального инструмента — D098

2026-10-30. Пользователь предложил выбирать пуансон/матрицу нажатием на изображение, убрать обычные выпадающие поля и учитывать несколько ручьёв одного корпуса. Дополнительное требование: оставить только настоящие инструменты, исключить учебные/условные варианты из рабочего выбора. Графический выбор и исключение условного режима **реализованы локально**. Форматы каталога v4 / `.bend` v12, SDK и VERSION не менялись.

## Основной экран

Две крупные области **Пуансон** и **Матрица** служат кнопками выбора. Короткая подпись с артикулом, стрелка раскрытия, рамка при наведении и клавиатурный фокус делают действие заметным. Сам контур остаётся главным содержимым. Без выбора — явная кнопка добавления/выбора, без придуманного стандартного клина.

Нажатие открывает привязанную к области графическую палитру: миниатюра реального сечения, артикул, необходимые рабочие размеры. Дублирующие комбобоксы пуансона/матрицы/ручья справа скрыты; они остались внутренними привязками существующей модели выбора, без отдельного пользовательского ввода. Источники, примечания и расширенные параметры переходят в подробности. Команда добавления DXF доступна в палитре; секции/наличие и подробности библиотеки остаются в панели задачи. При большом наборе допустим поиск по артикулу/V; он не заменяет обзор миниатюр.

## Один корпус — несколько рабочих вариантов

Четырёхручьевая матрица — **одна физическая запись с четырьмя рабочими вариантами**. В палитре под общим артикулом показываются варианты, например `2030-1`: **V16 / V22 / V35 / V50**. Каждый вариант содержит миниатюру того же полного корпуса, повёрнутого выбранным ручьём вверх. Нажатие выбирает сразу корпус и конкретный ручей; дополнительное раскрытие текстового списка V не требуется.

После выбора большой профиль показывает активную сторону. Под ним остаются короткие кнопки всех ручьёв этой матрицы с отмеченным текущим V. Четыре варианта удобно держать видимыми; отдельный выпадающий список здесь не нужен. Для одноручьевой матрицы дополнительный переключатель не показывается. Если одинаковые V соответствуют разным углам/сторонам, подпись дополняется углом либо идентификатором ручья.

В назначении сохраняются `die.id + groove`, а не новый ToolPreset на каждый V. Для графики/столкновений используется существующий `activeDieDrawing` и полный корпус с поворотом D072. Визуальная сортировка вариантов по V не должна менять сохранённые индексы ручьёв: элемент палитры хранит исходный индекс. Размеры/углы/повороты `2030-1` берутся из имеющейся записи, не из предполагаемого артикула.

Секции, количество и профиль принадлежат **общему корпусу**. Смена V не увеличивает наличие в четыре раза. Для разных последовательных гибов можно использовать тот же физический набор в другой ориентации; будущие одновременно установленные станции потребуют общего учёта расходования секций. Сам графический выбор такой многопозиционный учёт не объявляет реализованным.

## Только реальные инструменты

- Учебные записи и режим генерации условного пуансона/матрицы не входят в новый рабочий выбор. Во встроенном каталоге 0 записей с `teaching: true`; импортированные и сохранённые учебные записи также исключаются из выбора. Ручная генерация клина, переключатель условного режима и прежняя условная картинка удалены из рабочего интерфейса.
- Для показа и симуляции выбранного корпуса требуется загруженный действительный контур с известными единицами и поддержанными рабочими участками. Паспортные параметры/артикул без контура не превращаются в заводской профиль.
- Неполные записи реальных артикулов сохраняются для дополнения DXF/параметров. Они отдельно обозначены как требующие данных и недоступны для назначения; вместо картинки клина — состояние отсутствующего контура.
- Сохранённые старые проекты продолжают читаться. Условные назначения не выдаются за реальные и перед новой симуляцией требуют замены. Сам исходный STEP и старые записи не удаляются молча. Явное применение выбора с обоими поддержанными DXF включает реальные тела; простое открытие проекта не переписывает старый флаг. Ручной и полный маршрут с назначенными инструментами используют одну проверку полноты. Явный режим просмотра геометрии без инструмента сохраняется: в нём вообще нет тел инструмента и проверки столкновений с ними. Тестовые аналитические фикстуры остаются внутренними проверками и не появляются в пользовательской библиотеке.
- Приближённая сборка DemoPressV2 относится к модели станка, а не к библиотеке инструмента. Её статус/геометрия D088/D089 этим поручением не меняются.

## Выбор и ограничения

Нажатие на вариант применяет выбор к черновику интерфейса, обновляет профиль/размеры/секции и закрывает палитру. Наведение только выделяет вариант; активное назначение не меняется от движения мыши. Escape/закрытие без выбора сохраняют прежнее состояние. Возвращается фокус к кнопке профиля; выбор доступен с клавиатуры и имеет подпись артикул/V.

Текущий вариант отмечен рамкой и галочкой, а не только цветом. Enter/Space выбирают вариант; Escape отменяет. Поиск работает по артикулу, производителю и V. Палитра ограничена доступной областью монитора, список прокручивается. Недопустимый ручей остаётся видимым с причиной запрета; достаточный V не помечается как подтверждённая пригодность всей установки. Ограничения общего подбора/толщины/геометрии переиспользуются из действующей модели, без отдельной формулы внутри палитры. Если допустимы не все ручьи, блокируются только соответствующие варианты, не вся матрица. Другой V самовольно не подставляется.

Миниатюры строятся из существующих контуров и преобразований. QPainterPath большого профиля переиспользуется, пока профиль/ручей/ориентация не изменились; миниатюры живут только в открытой палитре. Отдельный 3D-контекст не создаётся. При изменении назначения открытая палитра закрывается; перед применением снимок повторно сравнивается с актуальной записью каталога. Навигация по палитре не выполняет 3D-поиск порядка и не запускает Boolean-проверки. Смена выбора отзывает прежний положительный результат; переход «К гибке» готовит текущую установку общим механизмом D097. Пуансон и матрица независимы; D096 для общей ориентации на шаге 0 сохраняется.

## Проверка реализации

Регрессионный набор проверяет отдельный выбор пуансона/матрицы, одно-/четырёхручьевой корпус, частично запрещённые варианты, отсутствие DXF, старые условные проекты, сохранение конкретного ручья и общее наличие. При одинаковых V кнопки рабочего экрана дополняются углом и исходным номером ручья. Варианты визуально сортируются по V без изменения сохранённого индекса. Поворот большого профиля/миниатюры/тела установки должен соответствовать одной записи. `app.graphic-tool-picker` проверяет клавиатуру, Escape, возврат фокуса, ограничение размеров палитры, отсутствие CAD-заданий при выборе и запрет слишком узких V после определения толщины. Для контакта, столкновений, многоручьевого корпуса и переносимости остаются существующие CAD/GUI-тесты. Native-графика только 100%; Windows/GPU — отдельная платформа проверки, D051 действует.
