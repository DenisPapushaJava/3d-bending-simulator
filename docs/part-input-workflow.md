# Исходные данные после импорта — D067

2026-10-28. Реализовано локально по поручению пользователя: автоматическое окно выбора материала и знакомства с распознанной толщиной после загрузки STEP, с учётом исследования DA-66T. По уточнению пользователя количество в эту форму не входит; существующие реквизиты PDF остаются в окне чертежа. [Действующий расчёт](flat-pattern.md), [происхождение толщины](sheet-thickness-project.md).

## Назначение и минимальный состав

После успешной загрузки новой детали показать одно компактное окно **«Исходные данные детали»**. Модель уже видна позади окна; ошибка/отмена импорта не вызывает его. Окно относится к текущему документу, не блокирует другие независимые окна приложения.

| Элемент | Поведение |
| --- | --- |
| Наименование | Имя исходного файла, без обязательного повторного ввода ID |
| Материал | Обязательный явный выбор для обычной расчётной подготовки: низкоуглеродистая сталь / нержавеющая сталь / алюминий. Подпись «Справочный пресет»; последний выбор не становится подтверждённым материалом нового STEP молча |
| Толщина, мм | Подставить найденное значение с обозначением источника. Подтверждение общей формы не превращает его автоматически в ручное переопределение или доказательство постоянства толщины |
| Краткая сводка | Число найденных гибов; если осевые длины различаются — диапазон и список по B-ID в «Дополнительно». Это не подтверждение полноты распознавания или готовности развёртки |
| «Дополнительно» | Радиусы и углы из STEP для справки. Применённое правило развёртки показано в основной части формы. |

Основное действие **«Продолжить»** принимает форму целиком и возвращает к обычному сценарию детали/выбора инструмента. Оно не означает «геометрия проверена». **«Только просмотр»**, X и Esc оставляют импортированную модель доступной без неподтверждённых расчётных параметров. Отдельный флажок/кнопка «подтвердить каждую грань/толщину» не нужны. Неполные обязательные данные блокируют основное действие, но не просмотр модели.

После принятия в панели остаётся короткая сводка `Материал · t · правило расчёта` и действие **«Изменить…»**, открывающее ту же форму. Не добавлять рядом дублирующие постоянные селекторы/подтверждения. Новый STEP получает собственные исходные данные; корректно заполненный `.bend` не требует повторного вопроса при каждом открытии. Старый проект без материала/с недостающими данными может открыть форму только для их уточнения. Существующий экспертный режим неизвестного материала с явным K не терять и не объявлять стандартным пресетом материала.

## Толщина и достоверность

Проверка различает подтверждённую геометрическую толщину, согласованное локальное измерение, ручное значение и отсутствие значения или конфликт. При заполненной толщине интерфейс кратко показывает её источник. При конфликте или отсутствии значения форма сообщает, что нужно исправить.

Используется `suggestThickness` с сохранением его происхождения. Отдельное предложение по толщинам распознанных прямых зон пока не добавлено; оно не должно подтверждать весь лист. Если источники дают разные значения, не выбирать минимальное/первое и не подставлять прежние 2 мм. При отсутствии значения поле показывает «Не определена», ввод ручной.

Грани-доказательства можно подсветить автоматически по текущей ревизии, как в существующем сценарии. Если требуется вращение/измерение заготовки, «Только просмотр» сохраняет доступ к сцене и последующему «Изменить…»; не создавать цепочку вспомогательных модалок.

Если пользователь меняет толщину относительно CAD, расхождение показывается непосредственно в форме. STEP не утончается/не масштабируется молча. Для расчётной подготовки сохраняются действующие проверки `ThicknessValidation`/`ThicknessConflict`; просмотр остаётся доступен. Фактическую измеренную толщину партии и номинальную толщину CAD в будущем можно разделить, но нынешний алгоритм не объявлять поддерживающим такую замену автоматически.

Простое принятие автоматически найденной толщины сохраняет её вычисленное происхождение. Отображение округлённого `6,00` не должно записать округлённую копию исходного числа в ручное поле без редактирования.

## Что реально влияет на развёртку

Существующее правило использует `BA = β · (Ri + K · t)`. Материал выбирает справочную зависимость K от Ri/t; при разных Ri на одной детали K может различаться. Поэтому основной экран не обещает один неизменный K для всего семейства металла. Для первой версии достаточно нынешних трёх справочных семейств; неподтверждённые марки/значения конкретного станка не подставляются.

Радиусы и углы готовой формы берутся из STEP. Выбор материала не изменяет их и не устраняет геометрические ограничения текущего builder. Требуемый радиус CAD и будущий радиус, предсказанный по материалу/инструменту, должны оставаться разными значениями с происхождением. Инструмент выбирается на своём этапе; его параметры не перегружают первичную форму.

Количество, имя, габариты и общая длина детали не заменяют осевую длину конкретного гиба. Для 3D-детали хранить/показывать L по каждой зоне; глобальное редактируемое L подходит только явно постоянному профилю. На чертеже сохраняется принятое соглашение: размеры полок с подтверждёнными наружными привязками, углы — внутренние.

## Что перенять из DA-66T

Изучено руководство автора Delem **DA-66T V0716, ПО 3.3**: [раздел 3.1](https://www.lzkcnc.com/wp-content/uploads/2022/11/DA-66T-V3.3-English1.pdf#page=57), [9.3](https://www.lzkcnc.com/wp-content/uploads/2022/11/DA-66T-V3.3-English1.pdf#page=164), [9.7](https://www.lzkcnc.com/wp-content/uploads/2022/11/DA-66T-V3.3-English1.pdf#page=178). Это документальная основа, не проверка версии/настроек пользовательского пульта.

В руководстве общие свойства изделия задаются перед построением; материал/толщина, библиотека материала и таблица поправок отделены. Заданный радиус можно отличать от пересчитанного после выбора инструмента. Эти принципы подходят нашему сценарию.

Свойства E/прочности/n не переносить в обязательную форму: нынешнее правило их не использует; n не является K. Значения по умолчанию пульта не считать паспортными данными любой марки. Delem-термин Bend Allowance и коррекции X нельзя численно приравнивать к нашей длине дуги BA без сверки определений. Совпадение результатов с Delem не заявляется.

## Калибровка позднее

Предлагаются два явно различных класса пресетов: **справочный теоретический** сейчас и **проверенный на образцах** после получения измерений. Будущие таблицы привязываются к марке/семейству, толщине, способу гибки, инструменту/V, углу и радиусу; хранят источник/версию и диапазон применимости. Поправка по измеренной полке и углу добавляется через понятное сравнение «рассчитано / измерено», с пересмотром результата, не незаметной глобальной заменой.

Правило K, табличный припуск BA и вычет BD — альтернативные представления согласованного расчёта, не три одновременно складываемые поправки. Пока таких образцов/проверенного конвертера нет, пункты калибровки не выглядят активными рабочими возможностями.

## Границы реализации и приёмка

- Форма открывается после принятия актуального CAD-снимка в сцену, один раз для последней загрузки; новый импорт/закрытие инвалидируют отложенное открытие и черновик старого окна. Несколько последовательных запросов не порождают очередь модалок.
- Поля редактируются в локальном черновике. Принятие валидирует и применяет согласованный набор в GUI-потоке к ожидаемой ревизии. Отмена не оставляет половину параметров в DocumentSession. Автоопределение не превращается в ручное значение; выбор материала/толщины инвалидирует связанные кэши по прежним правилам.
- Форма и команда «Изменить…» используют одну модель состояния. Геометрия/индексы граней не редактируются и не переносятся между импортами. Подтверждение формы не запускает тяжёлый CAD-пересчёт на каждый ввод символа.
- Материал, правило и ручная толщина сохраняются в существующем `.bend` v6; формат не меняется. Количество исключено из первичной формы по прямому уточнению пользователя и остаётся в окне PDF.
- Проверки реализации: автозначение 6 мм без старого значения; локальное/неоднозначное/отсутствующее значение; конфликт с CAD; неполная форма/просмотр; новая загрузка/отмена/закрытие; корректный проект/старый проект; отсутствие изменений по Cancel; одна фиксация формы и актуальность развёртки/PDF. GUI только при 100%, без HiDPI-дублей; D051 сохраняется.

## Владение и применение

`PartInputDialog` хранит копию параметров и неизменяемый документ. Отложенный показ привязан к геометрической и редакционной ревизиям; новый запрос инвалидирует его даже при последующей ошибке/отмене. Форма закрывается при начале работы контроллера, смене/закрытии документа или внешнем изменении параметров.

`DocumentSession::setPartInputs` проверяет обе ожидаемые ревизии, толщину, материал/экспертный K и правило до единственной фиксации. Одинаковое принятие не увеличивает ревизию. `ImportController` инвалидирует развёртку/PDF только при реальном изменении; кинематические кадры — только при изменении ручной толщины. Набор символов в форме не запускает worker.

На панели вместо прежних селекторов остаются сводка и «Изменить…». Подробные измерения/ручная толщина доступны в существующем свёрнутом блоке, с прежней проверкой доказательств. После «Только просмотр» действие развёртки при недостающих данных открывает ту же форму; «Продолжить» возвращает к текущему этапу без автоматического тяжёлого расчёта. Программные сценарии, собирающие параметры самостоятельно, могут явно выключить только автоматический показ через `setAutomaticPartInputPrompt(false)`; обычный запуск использует показ по умолчанию.

## Начальный K — D086

Правило развёртки теперь задаётся в «Настройки → Материалы». Встроенные категории предлагают справочную таблицу или постоянный K от 0 до 1. Для собственной категории задаётся постоянный K. Новая деталь получает актуальное правило при выборе категории.

Двойной щелчок по названию позволяет переименовать любую категорию. У встроенных категорий справочная строка определяется исходным типом материала. В редакторе «Марки для чертежа» каждая строка добавляет отдельный вариант в список PDF. Когда марка не выбрана, используется название категории.

Предел прочности при растяжении Rm задаётся в МПа один раз для категории и хранится в локальных настройках. У встроенных категорий есть ориентиры 400, 600 и 100 МПа соответственно для низкоуглеродистой стали, нержавеющей стали и алюминия. Значение можно заменить данными из паспорта листа или очистить, введя 0. Поле подготовлено для будущей оценки усилия гибки.

При открытии проекта форма показывает сохранённое правило. Выбор другой категории подставляет её актуальное правило. В поле «Коэффициент K» можно указать значение от 0 до 1 для этой детали или вернуть правило кнопкой «По категории». Сохранённый постоянный K для проекта без категории также можно редактировать.

«Продолжить» сохраняет выбранное правило в проекте и сбрасывает устаревшую развёртку и чертёж. Если развёртка открыта во вьюпорте, программа пересчитывает её сразу. Следующий чертёж и DXF используют новый расчёт. Настройки материалов при этом не редактируются.

До переноса правил в настройки, 2026-10-30. По выбору пользователя новый STEP без ранее заданного материала/K получает в **черновике формы** постоянный K = **0,45**. Выбор материала остаётся обязательным для обычного продолжения; толщина подставляется и проверяется как раньше. Форма сообщает начальный K, а «Дополнительно» остаётся свёрнутым, чтобы не перегружать первый экран.

В «Дополнительно» флажок **«Использовать постоянный K»** включён. Его значение можно изменить; выключение возвращает прежний справочник по выбранному материалу и Ri/t. Явное редактирование K сохраняет экспертную возможность задать его без материала. При новом значении используется прежний manualK и прежняя схема сохранения, а сводка нейтрально подписана «Постоянный K».

Правило становится входом расчёта только после «Продолжить»: до этого DocumentSession не меняется, а отмена/«Только просмотр» сохраняет отсутствие подтверждённых параметров. Заполненный проект сохраняет собственный K или явный табличный режим; открытие его формы не заменяет правило на 0,45. Версия справочных таблиц и кинематический K=0,5 не изменяются. Это пользовательский стартовый коэффициент теоретической развёртки, не новая калибровка материала/станка.
