# Инструмент из DXF — D071

Актуально D121, 2026-11-01: импортёр раскрывает внутренние `BLOCKS`/`INSERT`, включая вложенные блоки, базовые точки, поворот, равномерный масштаб X/Y и отражения. Оригинальный TOP.205.85.R08.dxf читается напрямую; его неизвестные единицы требуют явного выбора. Границы раскрытия описаны ниже. Каталог v5 / `.bend` v14 не менялись.

Актуально D117, 2026-10-31: встроенные 15 справочных записей удалены. Новая библиотека пуста; добавление контура и размеров — только из подготовленного DXF, без ручного ввода угла/R/V. Длина вдоль гиба и инвентарь задаются отдельно. [Действующий контракт](dxf-only-tool-library.md). Исторические описания прежних пресетов и ручных параметров ниже не являются текущим способом добавления инструмента.

2026-10-28. Реализовано локально по поручению пользователя. Дополняет [полные корпуса D068/D070](real-tool-simulation.md) и [каталог](tool-selection.md); D051 запрещает push/релиз без отдельной команды.

## Сценарий

D117: в основном окне только тип/название/длина инструмента и профиль. Метаданные/замена/единицы/контур/точный поворот/диагностика свёрнуты в «Дополнительно»; блок раскрывается при неоднозначности. Тип, единственные контур и известные единицы определяются автоматически. Можно перетащить один локальный DXF в окно (Copy); ручьи выбираются кнопками V, поворот/отражение находятся у профиля. Измерения показаны сводкой, инпутов угла/R/V нет.


После загрузки детали на этапе «Инструмент» нажать **«Добавить инструмент из DXF…»**. Выбрать файл, запись «Новый инструмент» либо существующий инструмент для замены его сечения. Выбрать замкнутый контур по слою/номеру, проверить масштаб в предпросмотре. Известные `$INSUNITS` выбирают мм/дюймы/см/м; при отсутствии/других единицах сохранение недоступно до явного выбора. Подготовленный контур хранится в мм.

Повернуть профиль числом градусов или отразить слева направо: пуансон носиком вниз, матрица ручьём вверх. Поворот не является ручным заданием рабочих точек: для симуляции действуют прежние строгие правила распознавания круглого носика/симметричного V. Контакт произвольных специальных инструментов ещё не поддержан.

Указать тип, название/артикул, производителя и **длину вдоль оси гиба**. Габариты сечения, рабочий угол/R носика либо V/углы/повороты рабочих сторон автоматически измеряются по DXF и доступны только для чтения. Высота сечения не используется как длина экструзии. Существующий ID/инвентарь сохраняются, новая запись получает UUID; размеры заменяемого сечения не переносятся со старого. При неизвестной длине либо неподдержанном/неоднозначном рабочем профиле сохраняется только контур для просмотра, без назначения/подбора. Кнопка сохранения не заявляет допустимую нагрузку.

Перед записью в общем CAD-worker строятся аналитический замкнутый wire/face и пробная экструзия 1 мм тем же кодом, что используется в симуляции. Самопересечение, некорректные дуги, недостоверное тело/нулевая площадь блокируют сохранение. Задание длины экструзии реального инструмента и проверка его контакта выполняются впоследствии в обычной проверке пары. Неизвестный контакт не заменяется клином автоматически.

Сохранение атомарное через `QSaveFile`: отдельный `tools/tool-catalog.json` рядом с файлом настроек. В Windows portable это `data/tools/tool-catalog.json`; Linux — папка пользовательских настроек. При обычном Windows-запуске с настройками в реестре используется AppLocalDataLocation, а не путь ключа реестра. Записывается снимок библиотеки мастерской, затем обновляется `tools/catalogPath` относительным путём от настроек, чтобы библиотека переносилась вместе с portable-папкой. Исходный DXF, исходный импортированный JSON и встроенный каталог не перезаписываются. При ошибке запись/выбор не меняются; отмена не оставляет частичную запись. Только после успешной записи новый инструмент выбирается в черновике. Применение к детали остаётся отдельной обычной командой. Проектные снимки других выбранных инструментов сохраняются в UI, но не публикуются в библиотеку автоматически.

Контур и SHA-256 захваченного исходного файла входят в каталог v3 и `.bend` v9; прежние каталоги v1–v2 и проекты v1–v8 читаются с их исходной семантикой. Координаты после выбора единиц/поворота/отражения сохраняются напрямую; SHA относится к исходным байтам, не к преобразованному JSON. Отсутствие DXF после сохранения не мешает использованию. Кадры и результат проверки не сохраняются. Отдельный редактор параметров без повторного выбора DXF пока не добавлен.

## Поддержка и ограничения

- Текстовый DXF до 4 МиБ / 200000 пар тегов. Чтение только локального файла, без скриптов, внешних ссылок или запуска CAD/Python.
- `LINE`, `ARC`, `CIRCLE`, простые 2D `POLYLINE`/`LWPOLYLINE`, включая знак bulge и круговые дуги без замены ломаной. Закрытые и собранные из отдельных рёбер контуры; направление обхода восстанавливается. Общая плоскость XY может иметь постоянное смещение Z.
- До 4096 рёбер в файле, 64 кандидатов, 512 рёбер в выбранном контуре. Концы сопоставляются в пределах `1e-6` единицы файла; новый соединяющий отрезок не добавляется. В мм после преобразования дополнительно действует строгая проверка `ToolDrawing`; большой разрыв не заполняется. Это не произвольный healing.
- Слои анализируются раздельно. Каждый независимый замкнутый компонент доступен для явного выбора. Один инструмент — одно сплошное сечение без внутренних полостей; выбор внешней петли не означает импорт тела с отверстиями. Разнесённые по слоям части одного контура нужно экспортировать вместе в одном слое. Наборы секций и переменное сечение не представлены такой экструзией.
- Подписи/размеры/точки и пространство листа оформления исключаются с сообщением. Открытые/разветвлённые компоненты перечисляются как пропущенные. Неподдержанная обычная сущность или параметры OCS/ширины/толщины исключают весь её геометрический слой с объяснением, чтобы не собрать усечённый корпус. Если других пригодных контуров нет — ошибка. Для использованного блока действует более строгий отказ всего импорта, см. ниже. `SPLINE`, 3D/mesh/fit-полилинии требуют экспорта сечения в линии/дуги.
- Ошибка чтения нового файла сохраняет предыдущий успешно захваченный контур; видимое имя файла и диагностика позволяют отличить их. Необработанный/неподдержанный контур не становится успешно проверенным инструментом.

### Блоки DXF — D121

Поддержаны внутренние 2D-блоки из перечисленных примитивов. Применяются база определения `BLOCK`, точка вставки, поворот в градусах, ненулевые масштабы с одинаковым модулем X/Y, независимый масштаб/смещение Z. Для INSERT допустимы OCS +Z и −Z; наклонные системы отклоняются. Круговые дуги и bulge остаются аналитическими, отражение меняет знак обхода. У самих примитивов прежний поддержанный OCS +Z. Геометрия каждого полученного слоя должна лежать в одной плоскости XY.

Вложенный слой `0` наследует слой вхождения, явно заданные слои сохраняются. Имена блоков сопоставляются без учёта регистра ASCII, для корректного UTF-8 — Unicode; для старых кодировок не-ASCII байты не перекодируются. Пустые определения допустимы; неиспользованные определения не превращаются в кандидаты. `ATTDEF` и корректно завершённая последовательность `ATTRIB`/`SEQEND` пропускаются как подписи. Бумажное вхождение не раскрывается. Комментарии 999 игнорируются.

Ссылки на отсутствующий блок, дубликаты определений, циклы, оборванные последовательности, неподдержанная геометрия использованного блока или его установка прерывают весь импорт с объяснением. Исключать только слой INSERT небезопасно: части его тела могут находиться на других явно заданных слоях. Неиспользованные определения с неподдержанными примитивами не мешают. Никакие части корпуса при отказе не публикуются.

Пока отклоняются неравномерные масштабы X/Y (дуга стала бы эллипсом), массивы MINSERT, внешние XREF, INSERT с application-defined группами/extension dictionary, в том числе возможным XCLIP. Обрезка и динамическое поведение не угадываются; нужно раскрыть такой блок в CAD. Служебные OBJECTS/связи владения не используются как контур и не ремонтируются. Это ограниченный импорт сечений, а не универсальный просмотр всех сущностей DXF.

Лимиты общие для всего файла: 20000 исходных записей ENTITIES/BLOCKS, 1024 определения, 16 уровней вложенности, 4096 вхождений, 20000 посещённых записей при раскрытии, 4096 полученных рёбер. Число вхождений и посещённых записей ограничивается и для повторных/пустых блоков, предотвращая экспоненциальное раскрытие. Координаты и коэффициенты преобразований конечны и ограничены по модулю `1e6`; итоговый масштаб не меньше `1e-9`. Проверка отмены выполняется при разборе и обходе. Блок читается по ссылке на определение, без создания полного промежуточного развёрнутого DXF.

Единицы берутся только из HEADER `$INSUNITS`; отдельные единицы блока не дают скрытого преобразования сверх записанных масштабов INSERT. Неизвестные единицы не становятся мм по артикулу. В каталог поступает прежний численный снимок после преобразований и выбора единиц; SHA-256 относится ко всем исходным байтам DXF. Исходный файл не переписывается, зависимости и схемы хранения не меняются.

## Архитектура и проверки

Чистый порт `application::ToolProfileImporter` получает путь либо захваченный `ToolDrawing`, возвращает кандидаты, результат проверки или ошибку. `project::DxfToolImporter` читает ограниченный ASCII DXF/хэш и делегирует финальную проверку узкому CAD-адаптеру. Новый модуль/сторонняя библиотека не добавлены. `ToolImportDialog` работает с численными снимками, не получает OCCT-типы. `ImportController` исполняет команды в существующем worker, отдельный ID/stop подавляет отменённый ответ; библиотечная операция не меняет DocumentSession/готовые кадры детали. Закрытие ждёт непрерываемый SDK-вызов по прежнему контракту.

`app.tool-dxf` проверяет линии/дуги и оба вида полилиний, единицы/слои/пропуски, bulge, бинарный/оборванный/слишком большой DXF, запрещённые OCS/ширины/флаги, самопересечение, численную точность замыкания против реального разрыва, UI с обязательными единицами, создание/обновление/инвентарную запись, неизменность библиотеки при отказе/отмене, отсутствие исходного файла и подавление позднего ответа. Fixtures собственные; частные DXF/извлечённые контуры не добавляются в репозиторий. Графические проверки только при 100%.

D121: `project.dxf-blocks` дополнительно проверяет известные координаты вложенных установок, отражения/OCS, замыкание между корнем и блоком, точные дуги/оба вида полилиний, слои/повторения, подписи, неизвестные единицы/исходный хэш и защитные отказы/лимиты раскрытия. В GUI-сценарии первое добавление выполняется из блочного DXF с неизвестными единицами. [Измерения и фактический охват проверки](development.md#d121--блоки-dxf-2026-11-01).


## Одна матрица с несколькими рабочими сторонами — D072

После выбора типа «Матрица», сечения и единиц автоматически проверяются положения 0°, +90°, 180°, −90°. Для каждого положения требуется единственный поддержанный симметричный V со скруглёнными касательными плечами и прямыми опорами. Ширина V и угол выводятся из геометрии, без таблицы артикулов. Неоднозначные/специальные контакты не угадываются; одинаковые V у разных сторон не назначаются автоматически. Это не произвольное определение рабочих баз.

Результат — небольшая таблица V/угол/поворот. Выбор строки показывает эту рабочую сторону в предпросмотре. Общий угол и строка V доступны только для чтения; ручного режима больше нет. Смена единиц, контура, исходного поворота/отражения или успешная загрузка другого DXF автоматически пересчитывает положения; старые значения не переносятся.

В основной панели достаточно выбрать V. Подбор, контакт, полный корпус в сцене/пересечениях и отчёт используют угол/поворот соответствующего ручья. Для одного инструмента не создаются четыре дубликата. Длина относится ко всей установленной матрице и задаётся отдельно от сечения. Ограничение V/t и проверка длины применяются к выбранной стороне; паспортные нагрузки и крепления по-прежнему не проверены.

Локальный пример пользователя — `2030-1`: V16/+90°/88°, V22/−90°/88°, V35/180°/85°, V50/0°/85°. Сохранены идентификатор и введённая пользователем длина 835 мм. Размеры/углы распознаны по DXF; длина не выводилась из 2D. На собственной t2/Ri2 заготовке с полками 40 мм и длиной зоны 40 мм прошли 12 полных циклов — четыре стороны с ST1405S/ST1405M/ST1701S. Отдельно проверены интерфейс и t6/Ri8 пример на V50; V16 для t6 заблокирован. Это ограниченная геометрическая проверка, не сертификат технологической пары для любой детали.

`ToolPreset.grooveSettings` хранит по одному углу/повороту на `openingsMm`. Пустой массив означает прежний общий угол/нулевой поворот. `dieGroove`/`activeDieDrawing` — общие чистые функции для параметров, подбора, распознавания, CAD и UI. Исходный контур не меняется при переключении. Каталог v3 / `.bend` v9 предотвращают молчаливое чтение новых данных старой программой; непустые положения под версией каталога ≤2/проекта ≤8 отклоняются. Офлайн Python-подготовка не понижает версию и не заменяет сечение с привязанными рабочими положениями — для этого служит GUI.
