# Отдельные зазоры между секциями — D172

2026-11-05. Первый блок ручной компоновки по поручению пользователя; по последующему поручению добавлен ограниченный [автоподбор D173](automatic-die-window.md). Основание — [анализ язычка внутри пролёта](axial-bend-placement-proposal.md#уточнение-язычок-внутри-пролёта-и-разрыв-матрицы).

**Уточнение пользователя:** паз/вырез детали сам по себе не требует разрывать матрицу. Сплошная матрица остаётся обычным вариантом, если проверенная установка/движение не дают коллизии. При будущем автоматическом подборе окно рассматривается только после реального конфликта с корпусом матрицы; промежуток между зонами задаёт допустимое место окна, но не необходимость его создания. Ручное окно также не становится обязательным по наличию паза.

## Данные и границы

`ToolAssembly` остаётся владельцем порядка строк захваченного склада. Пустой `jointGapsMm` означает прежний одинаковый `gapMm`; непустой содержит ровно N−1 значений, при этом `gapMm=0`. Не допускаются две одновременно действующие схемы, лишний конечный зазор, отрицательные/нечисленные значения, точность мельче 0,001 мм, один стык больше 1000 мм, более 512 секций, охват свыше 100000 мм, чужие строки и превышение количества. Рожки с неподдержанной 3D-формой по-прежнему не становятся прямыми секциями.

Общие функции core возвращают интервалы каждой секции и незакрытую длину заданного осевого интервала. Прежняя арифметика общей длины uniform-сборок сохранена, чтобы старые численные PressTools-снимки не расходились при чтении. Базовый планировщик D167 выдаёт прежние ограниченные варианты; отдельный D173 предлагает окно только после действительной коллизии. Максимальный фактический зазор используется при проверке разрешённого предела результата, а не устаревший uniform-параметр.

Пуансон и матрица имеют независимые сборки, по-прежнему центрированные на одной станции. Порядок секций задаётся в обычной ориентации инструмента. При Y-развороте пуансона тела и интервалы его зазоров поворачиваются вместе; отчёт охвата учитывает отражённую Z, включая отличающиеся длины двух сборок. Это не поворот детали. D169 двигает деталь относительно этих сборок. Склад и длины профиля не переписываются настройкой установки. Несколько станций, перестановка между операциями, сапожки и перенос детали не добавлены.

## Интерфейс

На этапе «Инструмент» рядом с составом каждого выбранного профиля есть «Секции…». Диалог показывает цветную численную схему и порядок секций. Можно выбрать прямые секции из захваченного наличия, добавить/удалить, сдвинуть секцию влево/вправо и задать зазор после неё. Зазоры относятся к физическим стыкам; перестановка секций не переносит окно. При удалении секции удаляется один смежный стык, остальные значения сохраняются; схема показывает получившийся результат до применения.

Превышение наличия блокирует «Применить». Отмена и применение без изменений не публикуют новую установку. При принятии повторно сверяются профиль и прежняя сборка. Меняется только соответствующая сборка, затем действует прежний сценарий назначения: 0 — вся деталь, положительный шаг — стабильный ID. Другой профиль/ручей/ориентация/склад не меняются. Сохранение назначения разрешено и для подрезанных зон: старая блокировка одиночного просмотра не является условием редактирования сборки. Само назначение не подтверждает цикл; расчётные ограничения и проверки сохраняются.

Обновление контекста/длины/области назначения не заменяет уже выбранную сборку автоматически. Недостающая сборка может быть предложена по прежнему алгоритму; пересчёт существующей выполняют явный подбор или выбор другого профиля. Короткое сохранённое назначение остаётся видимым с прежней блокировкой D127.

Схема, ввод и проверка количества выполняют только ограниченные численные операции. Boolean/meshing и проверка столкновений остаются в CAD-worker при запросе просмотра/проверки. Автоматического тяжёлого пересчёта на каждый ввод нет.

## Геометрия, опора и кэши

`segmentToolBody` вырезает каждую секцию по её фактическому интервалу. Эти же тела используются в сцене, коллизиях, упорах и sweep пуансона; окно не является графической маской. Дисковый дескриптор сборки получил ревизию `joint-gaps-v2` и все фактические зазоры. Равенство захваченных назначений включает список стыков, поэтому прежние точные single/draft/route ключи различают установки без нового большого кэша и без копирования DXF на каждую позицию.

Отдельно измеряется осевая длина активного материала без инструмента, для каждой сборки. Для совместного хода учитываются все реальные исходные интервалы; пустое место между ними не заполняется. В ручном/одиночном геометрическом просмотре неполная опора получает предупреждение, а столкновения по-прежнему останавливают показ. **Полный маршрут не принимается, если зазор перекрывает активный материал сверх прежнего CAD-допуска.** Это консервативная граница поддержанной модели, а не утверждение о физической невозможности гибки. Прежний uniform-зазор также не является доказательством внутренней опоры: прямые просмотры остаются доступны, но полный маршрут с потерей опоры больше не выдаётся за подтверждённый. Отказ по окну помечается отдельно (`axialSupportGap`): он зависит от положения детали и не прекращает пробы других привязок D169. Прежний независимый отказ по полосе материала не получает этот признак. Все три неудачные позиции при ненулевом диапазоне остаются неполным поиском. Точное отклонение кэшируется вместе с фактической установкой; при запросе без диагностики эта численная причина проверяется до создания кадров.

D100/D165 не разрешают внутренние потери опоры. Прежние проверки исходного материала, обе реконструкции, короткий инструмент, V, движение, станок, пол, упоры и независимое сравнение предшественника сохраняются. Непрерывная контактная механика, деформация/устойчивость/качество в окне не рассчитываются; оставшаяся длина секций не доказывает их достаточную жёсткость.

## Проекты и следующий блок

`.bend` v18 сохраняет `jointGapsMm` раздельно у каждой сборки. v1–v17 читаются с прежними одинаковыми зазорами; новый ключ под старым номером схемы отклоняется. Исходный STEP и библиотечные профили не меняются. Записи стартового склада не пересоздаются.

Ограниченный подбор одного окна добавлен впоследствии в [D173](automatic-die-window.md); сначала сравнивать порядок/общее смещение/другую форму инструмента. Сетка по миллиметрам и автоматическое разрешение внутренней утраты опоры не добавлены.
