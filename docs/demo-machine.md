# Демонстрационная сборка станка — D088

2026-10-30. По поручению пользователя добавлена встроенная **учебная сборка** с приближёнными собственными профилями по мотивам присланных экранов. Это не импортированная конфигурация и не точная модель SPEED BEND 3100-175. Исходные сведения/пробелы — в [исследовании](machine-profile-proposal.md). Действует D051: только локальная разработка.

## Пользовательский сценарий

На этапе **Инструмент** для новых/неназначенных инструментов **Демонстрационный станок включён по умолчанию** по уточнению пользователя 2026-10-30. Выполнить обычную проверку либо открыть ручной шаг; отдельно включать сборку больше не нужно. Выбор доступен и для каталога, и для ручных параметров. Он сохраняется в проекте вместе с инструментом каждого гиба; существующие назначения восстанавливают свой сохранённый режим, включая отсутствие станка. Изменение выбора снимает готовый результат и требует новой команды проверки, без автоматического поиска на каждое действие.

В меню **Вид** внутри сцены доступны **Показать станок** и **Весь станок**. Первое меняет только изображение: все препятствия продолжают учитываться в расчёте. В рабочем крупном виде показываются узлы в Z-окрестности габарита детали/инструмента и конкретное найденное препятствие; дальняя боковая рама не закрывает маленькую деталь полупрозрачной стеной. Второе показывает/вписывает сборку целиком с запасом под ленту; обычное вписывание возвращает крупный вид. Это только фильтр представления, не геометрическое удаление препятствий. Куб, якорь Y, размеры, лента и скорость 1×–3× остаются прежними. Узлы полупрозрачные, конфликтующие тела выделяются красным с названием пары. Охват учебной модели указан непосредственно рядом с результатом; импорт DXF/DLD и редактор станка в этот этап не входят.

## Геометрия и монтаж

`MachineModel::DemoPressV1` — стабильная ревизия встроенного профиля. Привязки и числа — часть этой ревизии: будущая другая геометрия должна получить новый идентификатор, чтобы сохранённый проект не изменил смысл незаметно. Построитель находится в CAD, работает на общем worker, публикует подготовленные неизменяемые тела. Viewer не вычисляет монтаж или столкновения. Qt/OCCT не добавлены в core/application.

Все величины в мм. **Y вверх, Z вдоль инструмента, X поперёк ручья**. Центр учебной станции — `Z = длина матрицы / 2`, рабочие узлы расположены симметрично вокруг него. Начало сцены остаётся у верха матрицы. Для демонстрации высота посадки взята из нижней границы фактически построенной матрицы и верхней границы пуансона; это приближение, а не распознавание реальных хвостовиков/креплений. Заглубление хвостовика, геометрия зажимов и его совместимость не доказаны.

| Узел | Собственный учебный профиль / размещение |
| --- | --- |
| Стол | Прямоугольное сечение 90×900, длина 3100; верх под адаптером |
| Адаптер матрицы | Упрощённое основание 80×30 с фасками, длина 3100; настоящий паз/зажим не восстановлены |
| Верхняя траверса | Прямоугольное сечение 55×1190, длина 3100; расположена над держателями |
| Держатели | Семь собственных упрощённых профилей высотой 120, секции по 100 через 400; центры Z −1200…1200 относительно станции. Фактическое наличие/разбивка неизвестны |
| Боковые рамы | Две отдельные C-образные призмы толщиной 150, свободный пролёт 2600. Задняя граница зева X=410; передняя поверхность X=80, ширина сечения до X=1450, высота 2100 от низа стола; учебное окно высотой 550 от верха стола |

Числа сочетают паспортные ориентиры и явно выбранные демонстрационные допущения. Например, окно 550 в собственном профиле не подтверждает базу измерения паспортного просвета, а 120 не объявляется измеренной общей высотой держателя с экрана. C-профиль намеренно упрощён, точные радиусы не восстановлены. Рама не выдавливается поперёк всего пролёта, промежутки держателей не заполняются. Общая боковина/траверса здесь не заменяет реальный чертёж станка.

Нижние узлы и боковые рамы неподвижны. Держатели и траверса получают то же смещение Y, что и пуансон, сохраняя взаимное расположение во всех подготовленных кадрах. Машинные тела не изменяют исходный STEP или его CAD-выбор. Чужие DXF/DLD/скриншоты из общей папки не включены в репозиторий/ресурсы приложения; новых библиотек нет.

## Проверка

Один `MachineAssembly::check` применяется в ручном префиксе и в полном цикле, а через него — в ручной проверке порядка/автоматическом поиске. Публикация положения требует успешного расчёта пересечений:

- вся расчётная деталь против каждого из двенадцати узлов;
- пуансон/матрица против узлов, кроме специально названных посадочных пар матрица–адаптер и пуансон–держатель;
- подвижные узлы против неподвижных.

Исключение посадочной пары не распространяется на деталь. Это ограничение собственной упрощённой посадки, не универсальное правило для будущего импортированного инструмента. Недопустимые пересечения/невыполнимый монтаж реальных зажимов этими исключениями сертифицировать нельзя.

Сначала выполняется консервативный AABB-отсев, затем точный OCCT Common с проверкой завершения/ошибок/валидности/конечного объёма. Численный порог объёма — `max(1e-5 мм³, 8 × tolerance³)`, без большого бюджета активной зоны гиба. Ошибка CAD не превращается в свободное положение. Проверяется расчётная копия листа по прежнему D029, отображение сохраняет вырезы. Контуры/зев самого станка этим приближением не заполняются.

Ручной результат сохраняет находку каждого кадра и разрешает просмотр остальных положений. Полный цикл при пересечении возвращает `MachineIntersection`, индекс и подготовленный диагностический кадр; он не даёт успешного Play/сертификата. Поиск может попробовать другую установку/порядок через тот же механизм. Чужой станок не наследует положительный результат: модель входит в PressTools/ToolAssignment, равенство RouteOperation и ключи D081/D082. Геометрическое основание детали остаётся независимым. Контроллер дополнительно сверяет модель принятого результата; скрытие/камера не меняют входы.

**Охват ограничен существующими положениями:** 21 в ручном гибе/одно для шага 0, 61 в полном цикле или одно в статичной установке. Промежутки движения, ввод/извлечение/перенос, задний упор, ход/просвет и усилие не подтверждены. Прежний непрерывный отвод пуансона проверяет его только против детали и матрицы; он не включает держатели/траверсу/раму или пуансон против станка. Само наличие двенадцати тел и отсутствие пересечений не доказывают изготовимость на реальном SPEED BEND.

## Хранение

`.bend` v11 хранит в параметрах и снимке назначения идентификатор `machineModel: "none" | "demo-press-v1"`. Чтение v1–v10 сохраняется с режимом без станка; учебная модель под старой версией и неизвестный/нетекстовый идентификатор отклоняются. Результаты, SDK-тела и кэши не сериализуются. Каталог v4, VERSION, SDK/зависимости и релизная схема прежние. Полный переносимый снимок пользовательских профилей/монтажа понадобится вместе с будущим импортом/редактором.
