# Допуск нехватки торцевой опоры — D100

2026-10-30. Пользователь предложил не блокировать геометрический просмотр из-за небольшого отсутствия материала у торцов: около 0,46 мм и до 3 мм. Реализован локальный настраиваемый предел **3 мм на каждом торце** по умолчанию. Это разрешение просмотра с предупреждением, а не норма допустимого свеса, проверка нагрузки, устойчивости или качества реального гиба.

## Сценарий

**Инструмент → Параметры установки → Допуск у торца**. Единицы — мм; 0 возвращает полную строгую опору. Предел применяется независимо к началу и концу линии гиба: 3 мм + 3 мм не считаются суммарным превышением. Дополнительных подтверждений нет. В пределах лимита при неполной опоре показывается жёлтая сводка с фактической нехваткой и лимитом; результат называется просмотром с неполной опорой, а не полностью подтверждённой установкой.

Настройка хранится в локальных предпочтениях `checks/maximumEndSupportLossMm`, без изменения `.bend` v12. Диапазон редактора 0…1000 мм — технический предел ввода, не разрешённый технологический диапазон. Старое значение отсутствует — используется 3 мм. Для прежнего случая с большей нехваткой требуется явно увеличить эту настройку. Настройка общая для одиночного гиба и проверки порядка; она не принадлежит профилю пуансона/матрицы.

Изменение значения отзывает готовые проверки и не запускает тяжёлый расчёт. Новая проверка получает снимок настройки; ответ применяется через прежнюю защиту ID/ревизий. Смена допуска не меняет STEP, назначения инструмента, материал, радиусы, развёртку или редакционную ревизию проекта. После открытия проекта кадры проверяются заново с локальным пределом.

## Общее правило проверки

Сохраняется D077: вычисляется прежняя консервативная полоса опоры на обеих полках по всему предусмотренному интервалу движения. Каждый отсутствующий объём должен примыкать ровно к одному торцу. Внутренний разрыв, нехватка по всей оси или отсутствие общей центральной полосы не разрешаются даже при большом допуске. Отверстия относятся к прежней проверенной D029-копии; внешний контур не заполняется.

Из разностей определяется общий осевой интервал материала `supportedFromMm…supportedToMm` внутри 0…L. Для разрешения просмотра одновременно требуется:

- `supportedFromMm ≤ допуск`;
- `L − supportedToMm ≤ допуск`;
- интервал содержит середину гиба и имеет положительную длину;
- обе полки повторно проходят полное вычитание внутри этого интервала.

Численный запас 4×CAD-tolerance относится к ограничению интервала и учитывается на границе допуска; он не является дополнительными миллиметрами технологического разрешения. Превышение предела возвращает `EndSupportLimitExceeded` с измеренным интервалом; UI сообщает нехватку и предлагает проверить V либо изменить настройку. Ошибка Boolean не превращается в отсутствие опоры или свободное положение.

Минимальное V, длина инструмента, диапазон контакта полок, углы, все пересечения и вертикальный отвод сохраняют прежние проверки. Допуск у торца не расширяет допустимое проникновение тел и не отключает столкновения.

## Контракты и кэши

Четыре порта начальной установки/движения получают `maximumEndSupportLossMm`; их низкоуровневое значение по умолчанию 0 сохраняет строгий контракт прежних вызовов. GUI передаёт локальное значение явно. `BendRouteRequest::maximumEndSupportLossMm` передаётся в тот же `buildBendOperation`; оно входит в ключ перехода. Снижение допуска не получает старый успешный результат из кэша, повышение — старый отказ.

Существующий низкоуровневый маршрут с явным `allowPartialEndSupport` и пустым пределом сохраняет прежний D077-просмотр без ограничения миллиметрами; GUI всегда задаёт предел. Ручной черновик D082 по-прежнему является просмотром с пересечениями, а не полным подтверждением опоры. Полная проверка ручного и автоматически найденного порядка использует одинаковую политику.

`BendEndSupport` и маршрутный флаг сохраняют прежний смысл. D163 публикует отдельную запись с началом для каждого реального интервала операции, включая полностью поддержанные: [совместная торцевая опора](joint-bend-support.md). Контроллер дополнительно проверяет отчёт относительно захваченного лимита. Готовая геометрия инструмента и постоянный SDK-кэш от допуска не зависят; меняется только результат проверки перехода. Форматы, зависимости, SDK и VERSION не менялись.

## Проверки

Собственные тесты используют исходный аналитический уголок с внешними торцевыми подрезами и конечные тестовые DXF-контуры, которые не входят в пользовательский каталог.

- `cad.end-support`: 0,46 мм; ровно 3 мм с каждой стороны; превышение 3,2 мм; строгий 0; запрет внутреннего разрыва и реального столкновения даже при большом лимите; NaN; смена лимита и кэш полного маршрута.
- `app.end-support`: значение 3 по умолчанию, жёлтое предупреждение одиночного гиба, фактическая нехватка, отзыв результата без автоматического CAD-задания, отказ после уменьшения лимита, восстановление и локальное сохранение без изменения проекта.
- Независимый `core`: численные границы общего helper без Qt/OCCT. Прежние тесты большого торцевого дефекта D077 явно задают 10 мм; предел 3 не объявляется геометрической невозможностью изготовления.

Локальная пользовательская деталь t=4/R4/L50 с округлёнными торцами: ST1405M + 2030-1 V35 прошли 61 положение при пределе 3 мм, включая демонстрационный станок и обе ориентации пуансона. Отчёт сохраняет нехватку около 0,46 мм на каждом торце. Этот прогон не является проверкой реального усилия/качества/устойчивости. Частная модель, контуры, логи и снимки остаются в игнорируемом `out/`.

D051: локально, без push/PR/релиза. Автоматические графические проверки только 100%; Windows/GPU отдельно не проверены.
