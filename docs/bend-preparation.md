# Подтверждение зон и целевые параметры

Актуальный путь UI и формат .bend v4: [D031, автоподготовка и каталог](guided-bend-check-workflow.md#реализация-g1g2--2026-10-18-d031). Описание этапа ниже сохраняет исходный технический контракт; новые зоны используют цель CAD без ручного подтверждения, старые решения сохраняются.


Текущий формат записи — **v3** с назначением инструмента и чтением v1/v2: [начальная установка](press-tool-setup.md). Ниже описан исходный этап; его геометрические ограничения сохраняются.

Дата: 2026-10-18, D020. Это подготовка данных перед M3. Распознавание остаётся [локальным геометрическим анализом](bend-recognition.md); подтверждение пользователем не является проверкой технологичности, постоянной толщины или возможности изготовления.

## Работа в интерфейсе

1. Открыть STEP либо `.bend`, выбрать зону слева. Оранжевая подсветка и блок «Измерено по CAD» относятся к исходной форме.
2. Выбрать «Не проверен», «Подтверждён» или «Исключён». По умолчанию все новые зоны не проверены. Исключение сохраняет зону в списке для повторного просмотра; оно не удаляет CAD-поверхности.
3. Для подтверждённой зоны задать целевой поворот и внутренний радиус, нажать «Применить задание». До этого поля только предлагают измеренные значения, а сохранённого задания нет. Кнопка применяет параметры к проекту в памяти; Ctrl+S записывает весь проект на диск.
4. «Сбросить задание» удаляет пользовательские параметры и возвращает предложение из CAD. При исключении либо возврате в непроверенный статус ранее сохранённое задание сохраняется, но не активно. После повторного подтверждения оно доступно снова.
5. Ctrl+S сохраняет статусы и задания в переносимый `.bend` v2. После открытия они восстанавливаются; выбор строки и камера не сохраняются. Изменения помечаются `*`, прежняя защита несохранённых данных действует и для этих правок.

Угол — **беззнаковый поворот от плоского состояния**, в application/core — радианы, в UI — градусы. 0° означает плоскость, 90° — прямой сгиб; это не внутренний угол между полками и не угол хода пресса. Начальный диапазон задания **1–179°**, конечный внутренний радиус **больше 0 и не больше 10⁶ мм**, оба числа конечны. Эти пределы задают область прототипа, не физическую выполнимость. В [ограниченном кинематическом просмотре](single-bend-preview.md) можно выбрать неподвижную полку и получить геометрическую плоскую модель для исходной CAD-формы. Полноценная операция с установкой, инструментом и производственной развёрткой ещё не задана. При несовпадении задания с CAD форма на экране остаётся исходной.

Можно подтверждать только найденные зоны. Ручное создание отсутствующего сгиба, редактирование маршрута, undo/redo и моделирование материала в этот блок не входят.

## Данные и владение

- `core::BendTarget` содержит только целевые угол/радиус и проверку диапазона. Qt/OCCT не нужны.
- `application::BendPreparation` содержит ID в пределах проекта, геометрическую привязку, `BendReview` и необязательный target. Это подготовка задания, а не исполнимая операция.
- `DocumentMetadata::bendAnalysis` остаётся неизменяемым измерением. `DocumentSession` владеет пользовательскими записями и соответствием текущим зонам; геометрическая ревизия не меняется от редактирования, ревизия редактирования увеличивается только при фактическом изменении.
- Команды применяются владельцем session в GUI-потоке. Импорт/сохранение блокируют редактирование из UI. Worker получает копию записей вместе со снимком документа; поздний ответ сохранения ограничен ID задания и edit revision.

## Восстановление привязки

ID вида `bend-1` создаётся для новой зоны и сохраняется в проекте; он не зависит от строки B01/B02 и номера грани. Пространство ID ограничено одним проектом. Это не универсальная система устойчивых имён CAD.

В запись входит геометрический отпечаток: концы оси в мм, измеренный поворот/внутренний радиус/толщина/осевой габарит, признак подрезки и минимальный общий прямой участок. После повторного анализа встроенного STEP программа сравнивает отпечатки с текущими зонами. Концы оси могут быть переставлены; мировые координаты сохраняются. Допуск длины — текущий допуск распознавателя, ограниченный диапазоном 10⁻⁵…0,01 мм, угла — 10⁻⁵ рад. Индексы поверхностей не записываются и не участвуют в привязке.

Применяется только взаимно однозначное совпадение: у записи одна подходящая зона, у зоны одна запись. При отсутствии/неоднозначности сохранённая запись остаётся в файле с прежним ID, решением и заданием, но не применяется к геометрии. UI сообщает количество таких записей слева и показывает их ID/статусы/параметры на вкладке «Сгиб». Неоднозначная зона недоступна для редактирования; ручная перепривязка пока не реализована. Новая зона без кандидатов получает новый непроверенный ID и пустое задание. Нельзя переносить правки просто по порядку B01/B02.

Привязка рассчитана на повторное открытие **того же встроенного STEP**, в том числе при изменении порядка найденных зон/граней. Загрузка другого STEP создаёт новый проект; перенос решений между изменёнными моделями не реализован. Изменение алгоритма, давшее другую геометрию, может потребовать разбирательства с непривязанными записями. Максимум 512 записей, включая непривязанные; сверх лимита новые записи не добавляются.

## `.bend` v2 и совместимость

Сохраняются общие поля [v1](sheet-thickness-project.md): `format`, `units`, `source` со строгими Base64/SHA-256 и `parameters.manualThicknessMm`. `version` теперь равен **2**. Новое обязательное поле `bends` — массив записей:

- `id`: уникальная строка из ASCII букв/цифр, `-`, `_`, от 1 до 64 символов;
- `review`: `pending`, `confirmed` или `excluded`;
- `geometry`: `axisStartMm` и `axisEndMm` (массивы трёх чисел), `angleRadians`, `innerRadiusMm`, `thicknessMm`, `lengthMm`, `trimmedEnds`, `minimumStraightLengthMm`;
- `target`: `null` либо объект `angleRadians`/`innerRadiusMm`.

Геометрия внутри `geometry` служит привязкой, не заменяет повторный CAD-анализ. Неверные типы, пропущенные обязательные поля, дубликаты ID, некорректные числа/статусы/задания и превышение лимита отклоняют проект до замены сцены. Валидная, но не совпавшая привязка сохраняется как непривязанная. Некорректное сохранение не перезаписывает существующий файл.

Чтение **v1 сохранено**: ручная толщина восстанавливается, для найденных зон создаются непроверенные записи без заданий. Само открытие не помечает проект изменённым; следующее явное сохранение пишет v2. V1 с полем `bends` отклоняется, чтобы данные не игнорировались. Неизвестные версии не открываются. Прежняя версия приложения, понимающая только v1, не сможет открыть v2.

## Проверки

`core.sequence` дополнен допустимыми/недопустимыми целевыми параметрами. `application.document-session` проверяет редактирование, dirty/edit revision, отсутствие изменений CAD, сброс/исключение, несовпадение, неоднозначность в обе стороны, перестановку зон, разворот оси, перенумерацию граней и защиту старого документа. `application.import-controller` проверяет отказ до presenter и снимок параметров в фоновом сохранении при новой загрузке/закрытии.

`project.portable-file` проверяет сохранение/восстановление статусов и параметров обычных/подрезанных сгибов, v1 → v2, ошибки схемы и повторное сохранение непривязанной записи. `app.step-workflow` проходит подтверждение/исключение, применение/сброс задания, Ctrl+S-сценарий через тот же контроллер, открытие, сохранность выбора и исходных измерений, блокировку при сохранении и сброс при закрытии. Его графический вариант проверяет наличие контрастной зоны при редактировании. Новых зависимостей и отдельных CI-задач нет; результаты платформ — в [development.md](development.md).
