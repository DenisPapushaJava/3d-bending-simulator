# Стартовая библиотека инструмента — D128

2026-11-01. Реализовано локально по прямому поручению пользователя включить подготовленные реальные профили в комплект для новых пользователей. Это уточняет пустую чистую установку D117; справочные записи без контура, условные клинья и учебные инструменты не возвращаются.

## Состав v1

Источник — явно выбранные активные готовые записи локальной библиотеки пользователя. Фиксированный снимок хранится в `src/project/data/starter-tools-v1.json`, исходная библиотека не редактируется и при сборке не читается. В наборе **7** профилей:

| Профиль | Вид | Рабочие ручьи | Номинальная цельная длина, мм |
| --- | --- | --- | --- |
| ST3408S | Матрица | V8 | 835 |
| ST3412S | Матрица | V12 | 835 |
| ST1405S | Пуансон | — | 835 |
| ST1701S | Пуансон | — | 835 |
| 2067-1 | Матрица, один четырёхсторонний корпус | V16 / V22 / V35 / V50 | 835 |
| TOP.205.85.R08 | Пуансон | — | 400 |
| 1063 | Пуансон | — | 835 |

ST2263 не включён: в сохранённой записи ещё не подтверждены рабочие параметры/длина. ST1405M, прежний 1063 и 2030-1 находятся в архиве и не включаются. В ходе задачи 2030-1 был перемещён из активных в архив; финальный снимок следует текущему выбору пользователя, а не восстанавливает удалённую запись.

Сохраняются точные захваченные линии/дуги в мм, SHA исходных DXF и рабочие стороны матриц. Удалены пути, личные остатки/архив и устаревшие подписи об условных формах; ID стартового набора стабильны. Номинальные длины взяты из сохранённых определений, не выведены из габарита сечения. Это стартовые настройки для геометрического просмотра, а не подтверждение фактической длины/наличия у получателя или паспортной нагрузки. Перед работой со своим оборудованием параметры библиотеки редактируются обычным способом.

## Первое открытие и обновление

Ресурс Qt встроен в `Bending::Project` и окончательный EXE; отдельный DXF или каталог рядом с программой не требуется. `readStarterToolCatalog` читает ограниченный JSON прежним reader. Composition root передаёт снимок существующему владельцу `application::ToolLibrary`.

Автоматическое создание разрешено только когда локальный файл библиотеки **отсутствует** и не задан явный внешний каталог. Существующий файл с пустым списком, только архивом или изменёнными профилями не засеивается повторно. `ToolLibrarySnapshot::exists` отличает первый запуск от намеренно пустой библиотеки; это поле порта в памяти, не изменение схемы JSON. При отсутствии настройки пути app проверяет прежний файл в стандартной папке, поэтому сброшенный INI не скрывает имеющуюся мастерскую.

Первый снимок записывается прежними QLockFile / проверкой ревизии / QSaveFile с запретом direct-write fallback. Только успешная атомарная запись публикует стартовый набор. Ошибка чтения, занятый файл или отказ записи оставляют прежние данные и показывают причину на этапе инструмента; усечённой копии или незаметного рабочего набора только в RAM нет. Подтверждений/модалок и сетевого запроса при инициализации нет.

Windows portable сохраняет пользовательскую копию в `data/tools/tool-catalog.json`; встроенный исходный набор принадлежит неизменяемому runtime. Упаковщик по-прежнему исключает пользовательскую `data`, но ресурс входит в EXE и его манифест. Штатные smoke/graphics-probes читают встроенный ресурс, однако не создают стартовую мастерскую в пользовательских настройках. Явный `--tool-catalog` также не запускает инициализацию.

Обновление стартового набора не сливает его с существующей мастерской, не возвращает удалённые профили и не подменяет назначения `.bend`. Чтение/неизменённое открытие библиотеки не переписывают файл. Удаление самого файла считается новым запуском; очистка списка через интерфейс — существующей пустой библиотекой.

## Секции без выдуманного наличия

В исходном ресурсе секции являются справочными шаблонами с нулевыми количествами. При создании пользовательской копии `segments` сбрасывается в null: **наличие неизвестно**, доступен прежний режим номинального цельного инструмента. Нулевой склад вместо отсутствующих сведений не создаётся, реальные количества пользователя не копируются.

В карточке соответствующего профиля показаны его стартовые длины с «—» вместо количества и выключенным «Указать наличие секций». Привязка шаблона — SHA **и полная геометрия** сечения/единицы/тип, не название или ID. Переименование не теряет подсказку, изменённый/повёрнутый контур с прежним SHA её не наследует. При уже заданном наличии используется только оно. Просмотр шаблона ничего не сохраняет и не назначает детали; после включения учёта пользователь вводит фактические количества.

Шаблоны длин не являются подтверждённой заводской разбивкой всех профилей. Сапожки пуансона остаются только строками учёта D119; их точная форма не выдумывается и в автоматическую сборку не включается. В шаблоны матриц не переносятся ошибочно заданные строки сапожков. Подбор инструмента/секций, минимальный V, коллизии и блокировка короткого инструмента D127 прежние.
